# 미국 시장 마감·장후 보고서

## 실행 모델

해석 포함 실행에 `--model-preset standard`를 적용한다. 상충 근거의 심층 검토 요청에는 `deep`, 자료 전용은 `--no-llm`을 사용한다. [저장소 모델 설정](../../../AGENTS.md#리서치-모델-선택)을 따른다.

`AGENTS.md`의 Market report 흐름을 따른다. 계좌 조회는 하지 않는다.

## 1. 실행 조건

- 동부시간 20:00 기준을 통과한 가장 최근 거래일을 사용한다. 주말·휴장일은 거래소 달력을 적용한다. 날짜 지정 옵션은 없다. 실행 시각을 `TZ=America/New_York date`로 확인하고 대상일을 사용자에게 알린다.
- 정상 생성 시간대는 대상일 20:00 ET 이후부터 다음 정규장 개장(09:30 ET) 전까지다(한국시간 겨울 기준 다음 날 오전 10시~오후 11시 30분). 개장 뒤 생성하면 공급자의 전날 장후 5분 봉과 최신 뉴스 범위가 줄고, 보고서 머리말에 늦은 생성 주의가 붙는다. 사용자가 특정 날짜를 원하는데 시간대가 지났으면 그 한계를 먼저 알린다.
- LLM 해석은 사용자가 보고서 생성을 명시적으로 요청했을 때만 켠다. 자료 전용 요청, 개발 검증, 재현성 확인에는 `--no-llm`을 쓴다.
- `discover --universe all` 같은 대량 Yahoo 실행과 동시에 돌리지 않는다(같은 IP의 Yahoo 제한으로 시장 폭·매크로가 미확인이 된다).

## 2. 실행

다른 명령과 묶지 않은 단독 명령으로 실행한다.

```bash
tradingagents market-report --no-llm --output-dir results/market-reports   # 공통 수집·계산·근거 출력
tradingagents market-report --output-dir results/market-reports            # LLM 해석 포함
```

결과 폴더(`results/market-reports/<대상일>-<id>/`)에 `report.md`, `report.html`, `evidence.json`이 생긴다. `results/`는 `quality-review.md`만 git이 추적한다.

## 3. 결과 해석

`evidence.json`의 `window`(대상일·기준·다음 개장·`late_generation`), 항목 `status`, `investigations`의 시작 사유·상태·근거 ID, `quality_warnings`를 본다.

| 상태 | 뜻 |
| --- | --- |
| `available` | 확인된 값 |
| `none_found` | 조회는 성공했고 해당 자료가 없음(기사·일정 없음). 경고 아님 |
| `partial` | 대용치·일부 실패 포함 |
| `stale` | 관측이 기준보다 오래됨. 금요일 선물은 17:00 ET, 조기 폐장일은 선물 폐장 15분 뒤·주식 17:00 ET 기준 |
| `unavailable` | 조회 실패 또는 수집 범위 밖 |

- 판정 "불완전 보고서"는 `quality_warnings`가 하나라도 있으면 나온다. 경고마다 원인이 공급자 한계(예: 최신 뉴스 50건이 모두 구간 이후), 생성 시각, 실제 결함 중 무엇인지 구분해 보고한다.
- LLM 해석은 근거 ID·숫자 금지 검증을 통과한 것만 들어간다. 실패하면 1회 재요청하고, 시도별 거부 사유가 `narrative_rejections`에 남는다.
- 시장 폭은 SPY 보유 종목 대용치(공식 S&P 500 구성 아님), 실적 확인은 대형주 7종목 표본, 주간 실업수당 발표 시각은 미수집이다.

[공통 시황 조사 기준](../references/us-market-research.md)의 기준 시각, 출처, 조사 시작 조건을 따른다. 평시는 자동 수집 결과를 사용한다. 급변·중요 근거 충돌·사용자 심층 요청은 공통 참조의 분담과 검증 절차를 적용한다. 미실행과 확인 실패를 각각 표시한다.

## 4. 보고 형식

1. 미국장 판단, 핵심 근거 2~3개와 근거 ID, 판단이 바뀌는 조건
2. 대상 거래일, 기준 시각, 생성 시각(늦은 생성 여부), 자료 충족 상태
3. 장기 투자자 관점(6개월~2년)의 이익 전망·실질금리·신용 여건, 트레이더 관점(1~5거래일)의 촉매·가격 반응·무효화 조건. 해석마다 근거 ID와 판단 변경 조건을 붙인다.
4. 추가 조사 시작 사유와 결과, 다음 거래일 공식 일정과 시각
5. 품질 경고와 원인, 미확인 자료

시장 폭이 미확인이면 상승 확산 판단을 유보한다. 골드만삭스 자료와 판교불패 영상은 당일 쟁점과 관련될 때 원자료와 대조한다. 상세 근거는 생성된 Markdown·HTML·JSON 보고서 경로로 연결한다.

목표가·수익률 전망을 쓰지 않는다. LLM 해석과 내가 정리한 내용을 구분해 밝힌다.

## 5. 품질 평가·재현성 기록

- 품질 평가를 요청받으면 같은 보고서를 Red Team·Blue Team 하위 에이전트로 독립 평가하고, 지적은 코드·실제 자료로 재검증한 뒤 반영한다.
- 기록은 그 보고서 폴더의 `quality-review.md`에 남긴다(생성 조건, 상태 집계, 경고와 원인, 조치). 여러 거래일 재현성은 같은 항목(상태·경고·시장 폭·뉴스 수·교차자산 변화율·장후 판정)을 날짜별 표로 비교한다.
- 코드 수정이 필요하면 `openspec-change` skill로 진행하고, 남은 일은 `openspec/NEXT_STEPS.md`에 적는다.
