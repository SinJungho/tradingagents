# chart-zones v1 계산 계약

구간은 `tradingagents/dataflows/chart_zones.py`의 float64 코드만 계산한다. 이 계약을 쓰는 표준 경로에서는 Tratto 응답으로 v1 수치를 다시 계산하거나 보정하지 않는다. 코드 버전 `chart_zone_params=v1`과 아래 계약이 다르면 보고를 중단하고 버전 차이를 확인한다.

| 설정 | v1 값 |
|---|---:|
| Yahoo 일봉 이력 | 최근 5년, 가용 자료만 사용 |
| 최소 유효 이력 | 504 XNYS 봉 |
| ATR | Wilder 14, 첫 14개 TR 평균으로 seed |
| ZigZag 확정 | 꼭짓점 ATR 기준 반대 방향 2.0× |
| KDE 커널 표준편차 | 각 피벗 ATR%의 0.5× |
| KDE 로그 격자 | 수집 기간 ATR% 중앙값의 0.05× |
| 후보 질량 | 밀도 높은 셀부터 누적한 50% HDR |
| 최대 구간 폭 | HDR 성분 피벗 ATR% 중앙값의 1.0× |
| 구간 최소 피벗 | 확정 피벗 2개 |
| 반응 관찰 | 피벗 뒤 20봉, 최대 5×피벗 ATR |
| 최근성 반감기 | 189봉 |
| 침투 기준 | 0.5×해당 세션 ATR |
| 추세 창 | 전체 이력 및 최근 252봉, 연간 환산 252봉 |
| 횡보 구분 | R² < 0.3 |
| 피보나치 앵커 | 마지막 확정 ZigZag 피벗 2개, 비율 0.236·0.382·0.5·0.618·0.786 |
| Anchored VWAP | 일봉 (H+L+C)/3 거래량 가중, 앵커는 피보나치 스윙 시작·최근 실적 발표 첫 세션(16:00 ET 이후 발표는 다음 세션) |
| 결과 제한 | 현재가 위/아래 각각 최대 3개, inside 최대 1개 |

50% HDR은 각 커널 바깥 6 표준편차까지 뻗은 로그 격자에 KDE 질량을 평가한다. 밀도 내림차순 누적이 50%를 처음 넘는 셀의 밀도를 threshold로 삼고, threshold 동점 셀을 모두 포함한 상위집합을 쓴다. 연결된 성분을 유지하고, 성분별 최대 폭은 한 번 계산해 50% 영역과 교집합으로 자른다. 이웃 후보가 겹치면 봉우리 사이 최저 KDE 셀에서 나눈다. 경계 피벗은 낮은 가격 구간에 한 번만 배정한다. 결과는 가격·날짜·점수 6자리, 안정 정렬로 직렬화한다.

백테스트에서 비교할 189/378/756봉 반감기 민감도는 튜닝 구간 안에서만 보고하고 검증 파라미터는 변경하지 않는다.
