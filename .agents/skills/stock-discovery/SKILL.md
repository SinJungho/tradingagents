# 종목 발굴

`AGENTS.md`의 Stock discovery 흐름을 따른다. 결정론적 스크리닝이며 팩터 간 통합 순위, 추천, LLM 분석을 만들지 않는다.

## 1. 입력 선택

| 상황 | 명령 |
| --- | --- |
| 사용자가 티커를 줌(최대 10개) | `tradingagents discover --tickers <T1,T2>` |
| 특정 구간 | `tradingagents discover --universe <section,...>` |
| 시장 전체 | `tradingagents discover --universe all` |

- 구간: `us-listed`(거래소 상장 보통주), `nasdaq100`, `sp500`, `russell1000`, `russell2000`, `sp400`, `sp600`, 시가총액 구간 `largecap`(100억 달러 이상)·`midcap`(20억~100억)·`smallcap`(3억~20억)·`microcap`(3억 미만), `all`. 쉼표로 여러 개를 고르면 겹치는 종목은 한 번만 계산한다.
- `russell2000`은 iShares IWM 출처가 CSV 대신 HTML을 반환하는 동안 실패한다. 단독 선택이면 실행이 원인과 함께 멈추고, 여러 구간에서는 출처 실패로 기록된 뒤 나머지가 계속된다. 대안은 `sp600`·`smallcap`이다.
- 실행 시간과 부하: `--tickers`는 짧고, `sp500`(503종목)은 약 2~3분, `all`(약 5,650종목)은 23~45분이다. 같은 IP에서 `all`을 하루 여러 번 실행하면 Yahoo가 응답을 늦추므로 하루 한 번 정도로 두고 `market-report` 등 다른 Yahoo 실행과 동시에 돌리지 않는다. 실행 전 예상 시간을 알린다.
- 다른 명령과 묶지 않은 단독 명령으로 실행한다.

## 2. 결과 해석

출력 순서: 요청·시도·반환 수, 구간별 종목 수와 출처, 팩터별 신호 분포(Bullish/Neutral/Bearish/Abstain)와 Bullish 후보, 구간·출처 실패, 종목별 공급자 실패, 단계별 시간과 호출 수.

- 출처 종류를 함께 전한다: Nasdaq-100·S&P 500/400/600·Russell 1000 목록은 2차 자료(Wikipedia)다. Nasdaq-100은 페이지에 적힌 날짜를 구성 기준일로 쓰고, 나머지는 기준일 미확인으로 조회 시각만 남는다. `us-listed`는 Nasdaq Trader 상장 파일, 시가총액 구간은 Yahoo 시가총액 스냅샷 기반 프로젝트 기준이며 지수 구성이 아니다. 시가총액을 못 받은 종목은 "Market cap unknown"에 모인다.
- Bullish 후보는 팩터별 점수 순 최대 10개다. 점수가 같으면(예: 다수의 +1.0000) 티커 알파벳 순으로 잘리므로, 동점이 많은 팩터의 상위 10개를 순위로 해석하지 않는다. 전체 분포와 동점 여부를 함께 알린다.
- Abstain은 입력 자료가 부족해 판단을 보류한 것이다. SEC에 XBRL 재무 사실이 없는 회사(주로 신규 상장)는 공급자 실패가 아니라 자료 없음으로 value·growth·quality를 보류한다.
- 종목별 공급자 실패(가격·SEC·분할 이력)는 일시 실패를 한 번 다시 조회한 뒤에도 남은 것이다. 실패 종목 수와 출처를 보고하고 정상값으로 대체하지 않는다.
- 스타일 신호는 `style-backtest`에서 예측력이 확인되지 않았다. 후보는 추가 분석 대상일 뿐 매수 근거가 아니라고 밝힌다.

## 3. 다음 단계

사용자가 후보 가운데 최대 10개를 직접 고르면 각 티커를 `stock-scenario` skill로 분석한다. 에이전트가 임의로 후보를 골라 LLM 분석을 시작하지 않는다.

## 4. 성능 측정(요청 시)

사용자 캐시를 지우지 않도록 `TRADINGAGENTS_CACHE_DIR`를 빈 임시 폴더로 지정해 첫 실행을 잰다. 가격 캐시는 당일 요청에 15분 TTL, SEC 캐시는 24시간이다. 단계별 시간·호출 수·실패 수와 함께 캐시 상태, Yahoo 429 재시도 수, 절전 여부 같은 조건을 기록하고, 조건이 다른 측정의 차이를 한 원인으로 단정하지 않는다.
