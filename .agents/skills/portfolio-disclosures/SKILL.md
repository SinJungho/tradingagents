# 공개 포트폴리오 공시

결정론적 스크립트 하나로 공식 자료만 읽는다. 13F는 SEC EDGAR, 하원 PTR은 하원 Clerk에서 가져온다. 숫자 계산(합산·비중·분기 비교)은 스크립트가 하고, 에이전트는 결과를 옮기고 한계를 짚는다. 매수·매도 추천이나 현재 보유 단정으로 바꾸지 않는다.

## 1. 대상 정하기

- 대상이 없으면 인기 투자자나 의원을 임의로 고르지 말고 이름을 묻는다.
- 13F는 운용사 이름이나 CIK로 지정한다. 인물은 운용사로 바꿔 넣는다(예: Buffett → Berkshire Hathaway, Ackman → Pershing Square, Dalio → Bridgewater Associates, Druckenmiller → Duquesne Family Office). 이름 검색은 최근 400일 안에 13F-HR을 낸 제출자만 찾는다.
- 하원의원은 성 또는 "이름 성"으로 지정한다. 이름 검색은 올해·작년 PTR 제출자 안에서만 한다.
- 결과 첫 줄의 이름·CIK·지역구가 사용자가 뜻한 대상인지 확인한다. "식별 모호"면 후보를 보여 주고 고르게 한 뒤 CIK나 "이름 성"으로 다시 실행한다.
- 상원의원은 다루지 않는다. 상원의원을 물으면 이 skill의 범위 밖이라고 알린다.

## 2. 실행

저장소 루트에서 다른 명령과 묶지 않은 단독 명령으로 실행한다. 패키지를 불러오며 `.env`의 `SEC_EDGAR_USER_AGENT`가 적용된다.

```bash
.venv/bin/python .agents/skills/portfolio-disclosures/scripts/disclosures.py \
  --filer 1067983 "bridgewater associates" --house Pelosi "Josh Gottheimer"
```

- `--top N`: 대상별 표시 행 수(기본 10). `--ptrs N`: 의원별로 읽을 최근 PTR 수(기본 5).
- 대상 하나에 몇 초 걸린다(JPMorgan 8,000여 종목도 약 5초). 필요한 호스트는 `www.sec.gov`, `data.sec.gov`, `efts.sec.gov`, `disclosures-clerk.house.gov`이다. Codex 샌드박스에는 외부 네트워크가 없으므로 코디네이터나 Claude 세션에서 실행한다.

## 3. 보여 주기(TUI)

스크립트 출력은 78칸 고정폭이며 한글 2칸 폭을 계산해 열을 맞춘다. 사용자에게는 출력 전체를 ` ```text ` 코드 블록에 그대로 옮긴다. Markdown 표로 다시 쓰지 않는다. 넓은 표는 좁은 터미널에서 줄이 꺾이고, TUI마다 표 렌더링이 다르다.

코드 블록 아래에는 세 줄 이내로만 덧붙인다.

1. 기준일: 13F 보고기간 말과 제출일, 하원 최근 PTR 제출일. 조회 시각과 구분한다.
2. 빈칸: 식별 모호, 판독 불가, 조회 실패, 비교 불가를 그대로 전한다. 0이나 무보유로 바꾸지 않는다.
3. 사용자가 물은 것에 대한 사실 한 줄. 예: "직전 분기보다 신고 주식 수가 줄어든 종목 6개".

## 4. 해석 한계

- 13F는 분기말 보유이며 분기 후 45일 안에 제출된다. 13(f) 증권만 담고 공매도·현금·비상장·해외 주식은 빠진다. 옵션 행의 가치는 기초자산 기준이다. 수정 신고는 RESTATEMENT면 전체를 대체하고 NEW HOLDINGS면 행을 더한 결과다. "기밀 처리" 표시가 있으면 일부 보유가 빠져 있다.
- 주식 수 변화는 신고된 수량끼리 비교한 것이다. 분할은 증가로, CUSIP 변경(합병·재편)은 신규와 미보고 한 쌍으로 보인다. 실제 매매로 단정하지 않는다. 티커는 13F에 없어서 발행사명을 그대로 쓴다.
- PTR은 거래 신고이며 보유 전체가 아니다. 금액은 신고 구간이므로 중간값, 주식 수, 현재 평가액으로 바꾸지 않는다. 소유(본인·배우자·공동·자녀)는 표시된 그대로 전한다. 스캔으로 낸 PTR은 글자가 없어 "판독 불가"가 되며, 원문 링크를 보고 직접 확인해야 한다. 옵션 행사가·만기는 원문 설명 칸에 있다.
- 하원 연간 재무공시(자산 목록)는 읽지 않는다. 요청하면 하원 Clerk 검색(https://disclosures-clerk.house.gov/FinancialDisclosure/ViewSearch)의 원문 링크를 안내한다.
