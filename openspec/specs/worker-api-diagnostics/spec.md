# worker-api-diagnostics Specification

## Purpose
Orca 워커와 하위 에이전트가 현재 실행 환경에서 사용할 수 있는 API 설정과 연결 상태를 안전하게 확인한다.

## Requirements

### Requirement: 현재 실행 환경과 인증 설정 진단

시스템 MUST 현재 프로세스의 작업 디렉터리, 확인 가능한 Orca 실행 환경, 선택된 quick/deep LLM 제공자와 인증 방식, 관련 인증 환경변수 이름 및 설정 여부를 표시해야 한다. ChatGPT plan 인증은 기존 로컬 인증 파일의 연결 상태만 확인해야 한다. 자격 증명 값이나 인증 파일 내용을 표시해서는 안 된다.

#### Scenario: 워커에서 설정이 누락됨

- **WHEN** 워커 프로세스에 선택된 제공자의 인증 설정이 없을 때
- **THEN** 시스템은 필요한 환경변수 이름과 누락 상태를 표시하고 그 값은 요청하거나 출력하지 않는다

#### Scenario: 인증은 부모 호스트에만 있음

- **WHEN** 현재 워커 프로세스에서만 진단할 때
- **THEN** 시스템은 현재 프로세스와 접근 가능한 로컬 인증 상태만 보고하고 부모 또는 원격 호스트의 설정을 추정하지 않는다

#### Scenario: Orca 컨텍스트가 제공되지 않음

- **WHEN** Orca 실행 환경 변수가 현재 프로세스에 없을 때
- **THEN** 시스템은 실행 환경이 프로세스에 노출되지 않았다고 표시하고 호스트를 임의로 지정하지 않는다

### Requirement: 비인증 API 도달성 확인

시스템 MUST 선택된 LLM API와 지원되는 데이터 API 호스트에 인증정보 없이 제한 시간 HTTP(S) 요청을 보내 도달성만 확인해야 한다. 시스템 MUST 리다이렉트를 따르지 않고 응답 본문, 요청 헤더, 쿼리 값 및 endpoint URL을 출력하지 않아야 한다.

#### Scenario: API 호스트가 응답함

- **WHEN** 인증 없는 연결 검사에서 HTTP 응답을 받을 때
- **THEN** 시스템은 호스트에 도달할 수 있다고 표시하며 HTTP 응답 본문을 읽거나 기록하지 않는다

#### Scenario: DNS 또는 네트워크 경로가 실패함

- **WHEN** DNS 해석, 연결 또는 timeout이 발생할 때
- **THEN** 시스템은 실패 범주만 표시하고 비밀값 또는 원시 네트워크 예외를 숨긴다

### Requirement: 비밀 없는 오류 진단

시스템 MUST API 실패를 DNS, 연결, 타임아웃, 인증, 권한, 호출 한도, 제공자 서버 또는 응답 오류로 분류하고 재시도 가능 여부를 표시해야 한다. 분류기는 응답 본문이나 예외 원문을 출력하지 않아야 한다. 어떤 범주에도 속하지 않는 실패는 예외 클래스 이름만 함께 표시해야 한다.

#### Scenario: 인증 거부 또는 계정 한도 초과

- **WHEN** API가 인증·권한 거부 또는 할당량 초과를 반환할 때
- **THEN** 시스템은 해당 범주를 표시하고 같은 요청을 자동 반복하지 않는다

#### Scenario: 일시적인 연결 실패

- **WHEN** 연결, timeout 또는 제공자 서버 오류가 발생할 때
- **THEN** 호출 경로는 제한된 재시도만 수행하고 최종 실패를 재시도 가능으로 표시한다

#### Scenario: 분류되지 않은 실패

- **WHEN** 실패가 어떤 범주에도 속하지 않을 때
- **THEN** 시스템은 "분류되지 않은 API 오류"와 예외 클래스 이름, 재시도 불가를 표시하고 예외 메시지는 표시하지 않는다
