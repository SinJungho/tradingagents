# 시장 보고서 LLM 해석 검증 실패 시 1회 재요청

## Why

2026-11-15 2026-11-13 대상 실제 LLM 보고서는 해석이 검증에서 거부돼 "불완전 보고서"가 됐다. 같은 근거로 다시 호출하자 해석 16개가 모두 통과했다. 해석 하나만 숫자·근거 ID 검사에 걸려도 전체를 버리는데 LLM 응답은 매번 달라 결과가 흔들린다. 거부 사유도 남지 않아 첫 응답이 왜 거부됐는지 알 수 없었다(2026-11-13의 "Russell 2000" 문제도 별도 재호출로만 찾았다). 포트폴리오 시나리오 종합에는 이미 형식 검증 실패 시 1회 재요청 방식이 있다.

## What Changes

- 해석 응답이 검증(JSON 형식, 섹션, 근거 ID, 숫자 금지)에 실패하면 사유 종류를 붙인 수정 지시로 한 번만 다시 요청한다. 이전 응답 원문은 재요청에 넣지 않는다.
- 각 시도의 거부 사유(해석 위치와 사유 종류)를 `evidence.json`에 남긴다. 응답 원문은 저장하지 않는다.
- LLM 호출 자체의 오류(네트워크 등)는 재요청하지 않는다. 두 번 모두 실패하면 기존처럼 해석을 제외하고 경고한다.

## Out of Scope

해석 일부만 남기기, 검증 규칙 변경, 재요청 횟수 설정.
