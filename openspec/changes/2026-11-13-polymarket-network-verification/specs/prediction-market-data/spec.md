## ADDED Requirements

### Requirement: 환경별 연결 검증 기록

연결 검증 기록 MUST 현재 환경과 집 네트워크를 구분하고 실제 공개 검색 GET 결과가 확보된 환경만 완료로 표시해야 한다. 상태·JSON 파싱 여부·검증 시각만 기록하며 인증정보와 응답 원문을 보존하지 않는다.

#### Scenario: 집 네트워크에 접근할 수 없음

- **WHEN** 현재 실행 환경에서 집 네트워크의 실제 결과를 확보할 수 없을 때
- **THEN** 집 환경 검증을 열린 상태로 유지하고 현재 환경의 성공으로 대체하지 않는다
