# 보고서 문구 문장화

## Why
요약 보고서 문구가 "SMA20 아래 · SMA50 아래; 월봉 SMA12 아래"처럼 가운뎃점·세미콜론·화살표로 나열되어 읽기 어렵다.

## What Changes
- humanize-korean(standard: 진단 → 윤문, 변경률 9.5%)으로 요약 페이지 문구를 다듬고 결과를 템플릿에 반영한다.
- 판정 근거, 일봉 이동평균 위치, 피보나치 스윙 헤드라인·해설·겹침, 장기 구조선 설명, 주의 문구, 차트 캡션, 머리말을 조사와 서술어가 있는 문장으로 만든다. 위·아래가 섞이거나 값이 없을 때도 문장이 성립한다.
- 반복되던 겹침 고지는 피보나치 도입 문단에 한 번만 둔다.

## Out of Scope
숫자·조건·고지 의미 변경, 5년 기본 보고서와 상세 보고서(`report_detail.html`)의 기존 문구.
