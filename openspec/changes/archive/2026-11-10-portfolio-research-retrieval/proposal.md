# Proposal

## Why

실계좌 심층 분석에서 분석 도구가 필수 날짜·검색 인자를 받지 못해 시세 지표와 뉴스 조회가 실패했다. 종목별 도구 라운드 제한도 최종 검증 시세 조회를 막았다. 도구 인자를 모델의 완벽한 입력에 의존하지 않도록 하고 분석 라운드에 검증 조회를 포함한다.

## What Changes

- 날짜를 생략한 분석 도구는 현재 실행의 기준일과 기본 조회 기간을 사용한다.
- 지표·거시 지표·예측시장 검색어가 생략되면 정해진 안전한 기본값을 사용한다.
- 포트폴리오 종목 조사에 검증된 시장 스냅샷 호출을 수행할 충분한 도구 라운드를 보장한다.
- ETF·뮤추얼펀드는 기업 재무제표 대신 Yahoo의 펀드 프로필·운용·보유 자료를 조회한다.
- Toss의 현재 USD/KRW 참고 환율을 조회해 유효 시간 안에서만 통화 통합 요약에 적용한다.
- 주문 이력과 별도로 거래내역을 조회해 거래 유형·자산군별 범위와 결제 상태를 요약한다.
- 공급자가 지원하지 않는 현재 보유 자산 범위나 재무자료는 추정하지 않고 미확인으로 남긴다.

## Capabilities

### Modified Capabilities

- `portfolio-scenario-analysis`: 분석 도구의 기본 인자와 검증된 시세 자료를 보장하고, 공급자 범위 밖 데이터는 명확히 부분 범위로 보고한다.

## Impact

- 분석 도구 스키마와 시장·뉴스·펀더멘털 분석 지침
- 포트폴리오 종목별 분석 라운드 예산
- 합성 데이터 기반 단위 테스트와 포트폴리오 분석 문서
