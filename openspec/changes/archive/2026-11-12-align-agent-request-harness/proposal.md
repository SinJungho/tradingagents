# 에이전트 요청 흐름 정렬

## Why

AGENTS.md와 종목 분석 스킬이 서로 다른 기본 경로를 안내한다. 심층 분석을 요청하지 않은 TQQQ 시나리오에도 전체 워크플로가 선택될 수 있고, 현재 지원하는 티커 목록 기반 발굴을 하네스 명세가 미구현으로 설명한다.

## What Changes

- 실계좌 허용 시 종목 시나리오의 기본 경로를 경량 `portfolio live --symbol`로 통일하고 전체 워크플로는 심층 요청에 한정한다.
- Toss 실계좌와 사용자가 제공한 보유 JSON 파일의 경로를 분리해 문서화한다.
- 지정 티커 발굴과 미구현 시장 전체 검색을 구분한다.
- 예측시장 활성 요구사항 이름과 검색 실패 설명을 선택 공급자 기준으로 정리한다.

## Out of Scope

- TradingAgents 실행 그래프와 API 동작 변경
- Kalshi 또는 Polymarket 공급자 구현 변경
- 저장소 변경사항 stage 또는 commit
