# 사용자 지정 종목 목록 탐색

## Why

현재 저장소에는 한 종목의 현재 또는 과거 데이터를 `value`, `growth`, `quality`, `momentum` 신호로 계산하는 결정론적 점수기가 있다. 사용자가 고른 소수의 미국 개별 주식에 이 기존 신호를 한 번에 적용하는 진입점이 없어, 데이터 공백과 종목별 실패를 일관되게 비교하기 어렵다.

## What Changes

- 최대 10개의 사용자가 제공한 미국 개별 주식 티커를 받는 호출 가능한 Python 진입점과 `tradingagents discover --tickers NVDA,AAPL` CLI 명령을 추가한다.
- 현재 데이터에 기존의 결정론적 네 스타일 점수기와 기준값만 적용한다. 입력 순서를 유지하고 종목별 팩터 신호를 반환하며, 점수의 교차 종목 정렬·합성 점수·종합 추천은 만들지 않는다.
- 누락 입력은 기존 `ABSTAIN` 신호와 부분 결과로 남긴다. 출처, 제공된 팩터 지표와 기준 날짜, 누락 입력, 종목별 실패, 요청·시도·반환 건수를 표시한다.
- 입력 개수와 티커 형식은 공급자 호출 전에 검증한다. 공급자 오류는 허용되는 범위에서 해당 티커 결과에만 격리한다.

## Out of Scope

- 시장 전체 스크리닝, 종목 목록 공급·발견, 시장 범위의 포괄성 주장
- 새 지표, 새 기준값, 합성 점수, 종목 간 순위, 투자 추천
- LLM 후속 분석, 과거 데이터 탐색, 브로커 접근 및 주문 처리
