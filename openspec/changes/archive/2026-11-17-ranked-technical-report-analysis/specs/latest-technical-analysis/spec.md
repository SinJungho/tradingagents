## ADDED Requirements

### Requirement: 우선순위별 기술 분석 포함
시스템은 보고서에 사용자가 제시한 12개 지표를 순위대로 싣고 각 항목의 목적·추천도·최신 차트 관찰값·조건부 해석을 포함하는 MUST 요구사항을 충족한다. 값을 검증할 수 없는 항목은 사유와 함께 평가 불가로 표시하며, 지표 계산 성공만으로 예측력을 주장하지 않는다.

#### Scenario: 실제 지표 해석 포함
- **WHEN** 최신 기술 보고서를 생성한다
- **THEN** 12개 지표가 사용자 순위대로 실제 계산 결과에 근거해 해석된다.

#### Scenario: 가격별 거래량 자료 미확보
- **WHEN** 검증된 Volume Profile 가격별 거래량 자료가 없다
- **THEN** 11위 항목을 평가 불가로 표시하고 일봉 거래량으로 POC·VAH·VAL을 만들어 내지 않는다.
