## ADDED Requirements

### Requirement: 차트 작업 중 브라우저 직접 쓰기 차단

차트 드로잉 요청이 활성화된 동안 에이전트 MUST 차트 캔버스를 좌표 클릭하거나 드래그해 표시를 바꾸지 않아야 한다. 탭 전환과 읽기 전용 화면 확인은 허용하며 차트 쓰기는 Tratto MCP를 사용해야 한다.

#### Scenario: 캔버스 좌표 입력

- **WHEN** 에이전트가 활성 차트 드로잉 요청에서 CUA 좌표 클릭이나 드래그를 호출할 때
- **THEN** 실행 hook은 호출을 거부하고 Tratto MCP 사용을 안내한다

#### Scenario: 읽기 전용 브라우저 확인

- **WHEN** 에이전트가 접근성 상태나 화면 캡처를 읽거나 요소 인덱스로 탭을 선택할 때
- **THEN** 실행 hook은 브라우저 확인을 허용한다
