# 포트폴리오 분석 데이터 보완

## Why

현재 Toss 연동은 일부 보유 손익 필드만 저장하고, 거래 내역은 유형별 건수로 축약한다. Toss가 제공하는 보유별 일간 손익·수수료·세금, 체결 기록, 현재가·캔들 및 응답 기준 시각을 분석 흐름에서 충분히 활용하지 못한다. 반복 실행 사이의 평가액 기록도 없어 실제 포트폴리오 변화 추이를 비교할 수 없다.

## What Changes

- 보유 요약·종목별 손익·수수료·세금 필드와 자료 기준 시각을 정규화 모델과 보고서에 보존한다.
- 거래 상세를 메모리 안에서만 처리해 완전한 거래 원장이 확인될 때에 한해 통화별 가중평균원가 기준 실현손익을 계산한다.
- Toss 공식 읽기 전용 현재가·일봉 캔들 API를 연결하고, 기준 시각을 갖춘 간결한 기술 분석 요약을 보고서에 포함한다.
- 라이브 실행 때 정규화된 보유 평가 스냅샷을 로컬 비공개 저장소에 추가하고, 이전 기록과의 평가액 차이를 요약한다.
- 계좌 식별자, 원시 계좌 응답, 종목별 거래 행은 프롬프트·로그·보고서·원격 추적에 포함하지 않는다.

## Out of Scope

- 주문·정정·취소·조건주문 또는 자동매매 기능.
- 토스 API가 제공하지 않는 기업 재무제표·밸류에이션·실적 추정치·시장 뉴스의 신규 공급자 추가.
- 세무 신고용 실현손익, 세금 로트 원장 또는 현금흐름 조정 총수익률로의 오인.
