# 검증 기록

- 포트폴리오 종합과 CLI 집중 테스트 45개 통과. 누락, 배열, 정제 후 빈 문자열 형태의 포트폴리오 영향 필드가 보정을 거치고, 보정 지시에 이전 응답 원문이 들어가지 않는지 확인했다.
- 루프백 바인딩을 허용하고 프록시 환경변수를 제외한 전체 실행에서 2,033개 통과, 1개 건너뜀, 하위 테스트 103개 통과. 건너뛴 테스트는 선택 패키지 `langchain_aws`가 필요하다.
- Ruff, CLI 도움말, OpenSpec 변경안 strict 검증을 통과했다.
- 2026-11-23 13:51 KST에 기존 TQQQ 조사와 동일 실행에서 저장한 정규화 계좌 요약으로 실제 종합 단계만 재실행했다. CLI의 종목 선택을 적용했고 단기·중기·장기 각 세 시나리오의 포트폴리오 영향 문자열을 확인했다. 계좌 자료 범위는 부분 확인이며 재검증 입력의 주문·거래 내역은 미확인이다. 결과는 로컬 `results/tqqq-research/2026-11-20/synthesis-replay.md`에 저장했다.
