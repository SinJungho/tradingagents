## MODIFIED Requirements

### Requirement: 시나리오 종합 형식 검증 실패 재요청

시스템 MUST 응답 추출 또는 형식 검증에 실패하면 종목 조사를 반복하지 않고 형식 보정 지시를 포함해 정확히 한 번 재요청해야 한다. 재요청도 응답 형식 검증에 실패하면 보고서 MUST 실패 단계와 안전한 검증 항목을 기록하고 이미 성공한 종목 조사 결과를 보존해야 한다. 진단에는 모델 원문이나 예외 원문을 포함하지 않아야 한다.

#### Scenario: 첫 응답 형식 오류 후 재요청 성공

- **WHEN** 첫 종합 응답이 JSON 파싱 또는 형식 검증에 실패하고 두 번째 응답은 유효할 때
- **THEN** 종목 조사를 반복하지 않고 유효한 시나리오 보고서를 생성한다
- **AND** 종합 모델은 총 두 번 호출된다

#### Scenario: 재요청 응답도 형식 오류

- **WHEN** 첫 응답과 단 한 번의 재요청 응답이 모두 형식 검증에 실패할 때
- **THEN** 보고서에 실패 단계와 검증 항목을 안전한 진단 코드로 기록한다
- **AND** 완료된 종목 조사 결과를 보고서에 보존한다
- **AND** 두 응답 원문이나 예외 원문은 기록하지 않는다

#### Scenario: 첫 응답 형식 검증 통과

- **WHEN** 첫 종합 응답이 유효할 때
- **THEN** 보정 재요청 없이 시나리오 보고서를 생성한다

#### Scenario: 포트폴리오 영향 자료 부족과 보정

- **WHEN** 종합을 요청하거나 포트폴리오 영향 필드가 형식 검증에 실패한다
- **THEN** 최초 요청은 아홉 시나리오의 필드별 자료형과 포트폴리오 영향의 정성 문장 사용 조건을 명시한다
- **AND** 보정 요청은 안전한 검사 코드를 포함하며 이전 모델 응답을 전달하지 않는다
- **AND** 결과의 포트폴리오 영향은 정제 후에도 비어 있지 않은 문자열이어야 한다
