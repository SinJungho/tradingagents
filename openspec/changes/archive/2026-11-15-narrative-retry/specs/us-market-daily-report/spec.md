## ADDED Requirements

### Requirement: LLM 해석 검증 실패 1회 재요청

시스템 MUST LLM 해석 응답이 JSON 형식·섹션·근거 ID·숫자 금지 검증에 실패하면 거부 사유 종류를 담은 수정 지시를 붙여 한 번만 다시 요청해야 하며, 이전 응답 원문을 재요청에 넣지 않아야 한다. 각 시도의 거부 사유(해석 위치와 사유 종류)를 근거 파일에 남기고 응답 원문은 저장하지 않아야 한다. LLM 호출 오류는 재요청하지 않아야 하며, 재요청도 실패하면 해석을 제외하고 품질 경고를 내야 한다.

#### Scenario: 첫 응답 거부 뒤 재요청 통과

- **WHEN** 첫 해석 응답의 한 해석에 수치가 들어 있고 재요청 응답은 검증을 통과할 때
- **THEN** 보고서는 재요청 해석을 쓰고 LLM 상태를 available로 두며, 첫 시도의 거부 사유를 근거 파일에 남긴다
- **AND** 재요청 메시지에는 첫 응답 원문이 들어가지 않는다

#### Scenario: 두 번 모두 거부

- **WHEN** 첫 응답과 재요청 응답이 모두 검증에 실패할 때
- **THEN** 해석은 제외되고 두 시도의 거부 사유가 남으며 품질 경고가 나온다

#### Scenario: LLM 호출 오류

- **WHEN** LLM 호출 자체가 예외로 실패할 때
- **THEN** 재요청하지 않고 LLM 상태를 failed로 둔다
