# 시나리오 종합 응답의 기간 이름 정규화

## Why

`portfolio live`의 4종목 실행이 연속 실패했다. 위치 진단 결과 종목별 조사는 모두 끝났고, 포트폴리오 종합 응답 검사(`_parse_synthesis`)가 기간 이름이 `short`, `medium`, `long`과 글자·순서까지 정확히 같지 않다는 이유로 `ValueError`를 내 전체 시나리오를 버렸다. 대소문자, "short-term" 같은 표기, 기간 설명 덧붙임, 순서 차이처럼 의미가 같은 응답까지 거부해 LLM 비용을 쓰고도 결과가 남지 않는다.

## What Changes

- 종합 응답의 각 기간 이름(`name`, 없으면 `horizon`)을 소문자로 바꾸고 앞쪽 영단어만 비교해 `short`·`medium`·`long`에 대응시킨다.
- 대응된 기간을 설정 순서로 재배열한다.
- 세 기간이 각각 정확히 한 번 대응되지 않으면 지금처럼 거부한다.

## Out of Scope

- 실패한 종합 응답의 자동 재요청, 구조화 출력 API 전환.
- 기간 이외 필드의 검증 완화.
