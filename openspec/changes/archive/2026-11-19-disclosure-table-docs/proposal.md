# 공시 스냅샷 표 목록 문서 정리

## Why

좁은 TUI 요구사항의 테두리 표 목록이 대상 요약·13F 상위 보유·하원 거래만 적고 있어, 이후 추가된 하원 주식 보유 표와 13F 신규·미보고 표가 빠져 있다. 사용자는 문서가 일관되게 반영됐는지 물었다(2026-11-19).

## What Changes

- 요구사항 본문과 표 구분 시나리오에 하원 주식 보유 표와 13F 신규·미보고 표를 더한다. 동작은 바뀌지 않는다.
- `openspec/NEXT_STEPS.md` 7번에서 이미 구현된 13F 티커 매핑을 뺀다.

## Out of Scope

- 출력 동작 변경
