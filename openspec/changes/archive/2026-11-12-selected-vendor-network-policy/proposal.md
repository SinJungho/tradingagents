# 선택 공급자 기준 워커 네트워크 정책
## Why
현재 네트워크 정책은 사용 중인 공급자 설정과 관계없이 지원되는 모든 데이터 API 호스트를 내보낸다. 제한형 egress 정책에 그대로 적용하면 사용하지 않는 목적지까지 허용할 수 있다.
## What Changes
정책 내보내기는 활성 데이터 공급자 체인과 도구별 재정의가 사용하는 호스트만 포함한다. 고정 설정 없는 sentiment 입력과 사용 설정된 Toss 및 TypeSafe 목적지는 별도 조건에 따라 반영한다. 진단 명령은 지원 API 전체를 계속 검사한다.
## Out of Scope
호스트 네트워크 정책 적용, API 요청 동작, 지원 공급자 목록, 기본 공급자 선택은 변경하지 않는다.
