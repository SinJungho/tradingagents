# 포트폴리오 보고서의 선택 자료 실패 기록과 미분류 오류 유형 표시

## Why

`portfolio live` 실행에서 FRED 키 누락과 Polymarket 연결 끊김이 로그에만 남고 보고서의 "누락과 실패"에는 "별도 누락 항목 없음"으로 표시됐다. 선택 자료는 라우터와 공급자가 대체 문구로 흡수해 실행은 계속되지만, 보고서 독자는 어떤 자료가 빠졌는지 알 수 없다. 또 시나리오 단계가 "분류되지 않은 API 오류"로 실패했을 때 원인 단서가 전혀 남지 않아 재실행 여부를 판단할 수 없었다.

## What Changes

- 데이터 라우터가 선택 자료를 대체 문구로 내보내거나 모든 공급자가 응답하지 못한 경우, Polymarket 검색이 네트워크 오류로 실패한 경우를 실행 단위로 기록한다.
- `portfolio live`는 시나리오 단계 전후로 이 기록을 모아 보고서의 `source_failures`에 메서드별 안전한 오류 범주·재시도 가능 여부·발생 횟수로 넣는다. 시나리오 단계가 실패해도 모은 기록은 남긴다.
- 오류 분류가 `unknown`이면 예외 클래스 이름만 함께 표시한다. 예외 메시지, 응답 본문, 자격 증명은 계속 표시하지 않는다.

## Out of Scope

- 단일 종목 분석(`tradingagents --ticker`) 보고서의 선택 자료 실패 표시.
- Polymarket 재시도 정책 변경, 새 오류 범주 추가.
