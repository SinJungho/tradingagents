## MODIFIED Requirements

### Requirement: 시나리오 API 실패 원인 표시

시스템 MUST 심볼 조사와 시나리오 종합 API 실패를 안전한 오류 범주와 재시도 가능 여부로 표시해야 한다. 시스템 MUST 시나리오 단계에서 선택 자료(거시 지표, 예측시장 등)가 조회되지 않아 대체 문구로 처리된 경우를 데이터 메서드, 안전한 오류 범주, 재시도 가능 여부, 발생 횟수로 보고서의 실패 목록에 기록해야 한다. 시스템 MUST 원시 예외, 공급자 응답 본문, 자격 증명 및 계좌 식별자를 보고서에 포함해서는 안 된다.

#### Scenario: 일부 심볼 조사 실패

- **WHEN** 일부 종목의 시장 조사 API 호출이 실패할 때
- **THEN** 성공한 분석은 보존하고 실패 종목에는 실패 범주와 재시도 가능 여부를 표시한다

#### Scenario: 시나리오 모델 호출 실패

- **WHEN** 시나리오 종합 모델 API 호출이 실패할 때
- **THEN** 포트폴리오 보고서에는 실패 범주와 재시도 가능 여부만 기록하고 원시 응답은 남기지 않는다

#### Scenario: 선택 자료 조회 실패

- **WHEN** 시나리오 단계에서 거시 지표 공급자 설정이 없거나 예측시장 검색이 네트워크 오류로 실패할 때
- **THEN** 보고서의 "누락과 실패"에 해당 데이터 메서드, 오류 범주, 재시도 가능 여부, 발생 횟수가 표시된다
- **AND** 같은 메서드와 범주의 반복 실패는 한 줄로 합쳐진다
- **AND** 시나리오 단계 자체가 실패해도 그때까지 모은 선택 자료 실패가 표시된다
