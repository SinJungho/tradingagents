## ADDED Requirements

### Requirement: 단일 종목 CLI 자료 실패 표시

시스템 MUST `tradingagents --ticker` 실행의 선택 자료 조회 실패를 실행 단위로 모아 완료 보고서에 자료 메서드, 안전한 오류 범주, 재시도 가능 여부와 발생 횟수로 표시해야 한다. 같은 메서드와 오류 범주의 반복은 한 줄로 합쳐야 한다. 보고서는 원시 예외 메시지, 공급자 응답 본문, 자격 증명 또는 계좌 식별자를 포함해서는 안 된다. 시스템 MUST 새 실행 전 미처리 실패와 실행 단위 차단 상태를 초기화하고, 실행 실패를 모은 뒤 drain해 차단 상태를 초기화해야 한다.

#### Scenario: 선택 자료 실패와 반복 차단

- **WHEN** 단일 종목 실행에서 선택 자료 조회가 네트워크 오류로 실패하고 같은 실행의 후속 조회가 차단될 때
- **THEN** 완료된 Markdown·HTML 보고서와 전체 보고서 화면에 해당 실패를 메서드·범주·재시도 가능 여부·횟수로 집계한다
- **AND** 예외 메시지나 응답 본문은 보고서에 포함하지 않는다

#### Scenario: 오류가 없는 실행

- **WHEN** 단일 종목 실행 중 선택 자료 조회 실패가 없을 때
- **THEN** 보고서에 빈 실패 항목이나 허위 누락 항목을 만들지 않는다

#### Scenario: 다음 실행으로 차단 상태가 넘어가지 않음

- **WHEN** Polymarket 조회가 차단된 실행의 실패 기록을 drain한 뒤 다음 단일 종목 실행이 시작될 때
- **THEN** 다음 실행은 Polymarket 조회를 다시 시도할 수 있다
