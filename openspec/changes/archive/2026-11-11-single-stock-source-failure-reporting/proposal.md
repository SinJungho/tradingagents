# 단일 종목 보고서의 자료 조회 실패 표시

## Why

포트폴리오 시나리오 보고서는 선택 자료 실패를 `source_failures`로 집계하지만, 기본 `tradingagents --ticker` 경로는 같은 실패를 보고하지 않는다. Polymarket 연결 실패가 같은 실행에서 차단되어도 그 기록이 단일 종목 Markdown·HTML 보고서에 남지 않아 독자가 분석의 자료 공백을 확인하기 어렵다.

## What Changes

- 단일 종목 CLI 실행 전후에 자료 실패 기록을 drain해 이전 실행 기록을 섞지 않고 Polymarket 실행 단위 차단 상태를 새 실행에 넘기지 않는다.
- 분석 완료 보고서에 자료 메서드, 안전한 오류 범주, 재시도 가능 여부, 발생 횟수를 집계해 표시한다.
- 요약을 Markdown, HTML, 전체 보고서 화면에 같은 내용으로 제공하고 예외 메시지나 응답 본문은 노출하지 않는다.

## Out of Scope

- 분석 도구의 자료 조회·재시도 동작 변경
- 포트폴리오 보고서의 실패 집계 변경
- 분석 중단으로 완성 보고서를 만들지 못한 실행의 별도 오류 보고서 생성
