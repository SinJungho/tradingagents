# Design

## Context

기본 대상은 Nasdaq, NYSE, NYSE American 등 미국 거래소에 상장된 보통주와 ADR이다. ETF·뮤추얼펀드·ETN, 우선주, 워런트, 권리, 유닛, 테스트 증권은 제외한다. OTC 종목은 별도 출처와 적격성 판정이 없으므로 초기 범위에서 제외하고 보고서에 범위를 표시한다.

## Decisions

### 구간

- 지수별: Nasdaq-100, S&P 500, Russell 1000, Russell 2000, S&P MidCap 400, S&P SmallCap 600
- 시장 전체: 적격 미국 상장 보통주 전체
- 규모별: 프로젝트 기준 대형(시가총액 100억 달러 이상)·중형(20억 이상 100억 달러 미만)·소형(3억 이상 20억 달러 미만)·초소형(3억 달러 미만). 이는 지수 제공자의 공식 분류가 아닌 현재 시장가치에 대한 명시적 구간이다. 분류 기준과 시가총액 자료 시각은 출력에서 확인 가능해야 한다.

지수 구간은 서로 겹칠 수 있다. 종목의 지수 소속을 중복 제거해 잃지 않고, 시장 전체 결과의 고유 종목 수와 각 구간 종목 수를 따로 집계한다.

Nasdaq Trader의 동적 상장 파일을 유니버스의 출발점으로 쓴다. 파일은 상장 거래소와 ETF·테스트 표시를 제공하지만 모든 증권 유형을 완전하게 분류하지는 않으므로, 이름으로 명백한 비보통주를 제외하고 결과에는 이 필터 한계를 적는다. OTC 종목은 제외한다.

기존 네 팩터를 그대로 쓰며 합성 점수나 종합 순위를 추가하지 않는다. 전체 시장 선별은 LLM을 호출하지 않는다. 사용자가 직접 선택한 최대 10개 후보만 기존 단일 종목 분석 흐름으로 넘긴다.

## Data Flow

1. 갱신 가능한 Nasdaq Trader 상장 종목 파일에서 거래소·ETF/테스트 여부·파일 생성 시각을 읽고, ETF·테스트 및 명백한 비보통주 유형을 제외한다. OTC 종목은 포함하지 않는다.
2. 지수 구성 목록을 출처별로 가져와 해당 구간의 티커와 출처가 제공한 기준일 또는 목록 조회일을 검증한다.
3. Yahoo Finance 스크리너의 현재 시가총액과 조회 시각을 확인해 규모 구간을 분류한다. 자료가 없으면 규모 미상으로 둔다.
4. 가격·SEC 재무·분할 자료를 사용해 기존 `value`, `growth`, `quality`, `momentum` 신호를 계산한다. 신규 합성 점수나 단일 종합 순위를 만들지 않는다.
5. 섹션별 후보 신호와 종목별 자료 공백·실패를 반환한다. 깊은 LLM 분석은 명시적으로 선택된 최대 10개 이하의 종목만 허용한다.

## Data Contracts

- 거래소 상장 종목 파일, 지수 구성 목록, 시가총액 자료는 각각 출처·URL·기준일 또는 조회 시각을 별도로 보존한다.
- 지수 제공자의 공식 구성 자료를 자동으로 사용할 수 없는 구간은 공개 2차 목록 또는 추종 ETF의 보유종목을 사용하고, 이를 공식 지수 구성으로 단정하지 않는다. Russell 2000의 iShares IWM 보유종목은 지수 구성 프록시로 표기한다.
- 목록 개수·티커 형식·중복을 검증하지 못하면 해당 유니버스 실행을 실패 처리한다. 코드에 고정한 과거 목록으로 대체하지 않는다.
- 전 종목 팩터 계산은 종목당 가격·SEC 재무·분할 자료 조회를 요구하므로 요청·시도·반환 수, 재사용 가능한 캐시 동작, 구간별 실패를 관찰 가능하게 한다. 개발 검증은 합성 자료만 사용한다.

## Risks and Trade-offs

- S&P 500, Russell 1000, S&P MidCap 400, S&P SmallCap 600 공개 구성 목록은 2차 출처이며, Russell 2000은 IWM 보유종목 프록시다. 결과에 이를 명시하고 기준일을 보존한다.
- 각 종목의 가격·재무·분할 자료를 확인하므로 `all` 실행은 오래 걸릴 수 있고 공급자 제한에 걸릴 수 있다. 요청·시도·반환 수와 실패를 보여 주며 자동 LLM 호출은 하지 않는다.
- 시가총액 규모 경계는 프로젝트가 선택한 현재 가치 구간이며 지수 제공자의 공식 분류가 아니다.

## Verification

- 공급자 응답을 합성 fixture와 패치된 함수로 대체해 목록 파싱, 상장 증권 필터, 중복 티커, 출처 실패, 시가총액 경계, 부분 실패, CLI 경로를 검증한다.
- live 시장 전체 스캔과 실계좌·LLM 호출은 테스트에서 실행하지 않는다.
