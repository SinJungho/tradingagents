# 모든 외부 데이터 API의 네트워크 진단과 제한 재시도

## Why

TradingAgents의 외부 조회 경로는 `requests`, 표준 라이브러리, yfinance 및 LLM SDK로 나뉘어 있어 DNS·연결·TLS·인증 문제를 같은 기준으로 구분하기 어렵다. 일시적 전송 실패는 조회 결과가 없는 것처럼 보일 수 있고, 진단은 일부 데이터 호스트만 점검한다.

## What Changes

- 공개 데이터 제공자 호스트를 현재 프로세스에서 인증 없이 점검하도록 `tradingagents doctor` 진단 범위를 보강한다.
- API 오류 분류에 TLS 실패를 추가하고 DNS, 연결, 시간 초과, TLS, 인증·권한·한도 오류를 구분한다.
- 멱등 GET 조회와 Yahoo 조회에만 소수의 지수 백오프 재시도를 적용하고, 오류 로그에는 제공자·호스트·오류 범주·시도 수만 남긴다.
- API 키와 응답 본문을 기록하지 않으며, 실행 환경의 DNS·아웃바운드 정책을 저장소 코드로 우회하지 않는다.

## Out of Scope

- 샌드박스, macOS, VPN, DNS 리졸버, 방화벽 또는 운영 환경의 네트워크 정책 변경
- POST 인증·LLM 요청의 자동 재실행
- 현재 프로세스 바깥의 네트워크 상태 추정 및 실계정/실LLM 호출
