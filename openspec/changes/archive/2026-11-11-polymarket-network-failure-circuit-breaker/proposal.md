# Polymarket 연결 실패 시 실행 단위 차단

## Why

반복된 Polymarket 연결 실패가 같은 분석 실행에서 매번 재시도되어 지연과 오류 기록을 늘린다. 실패한 조회의 대체 문구가 예측시장 수치의 추정을 명확히 막지 않아, 출처가 확인되지 않는 확률이 분석에 섞일 수 있다.

## What Changes

- 연결·DNS·타임아웃 오류가 발생하면 해당 실행의 이후 Polymarket 조회를 네트워크 요청 없이 차단한다.
- 차단된 조회도 기존 데이터 실패 기록에 포함해 보고서의 발생 횟수를 유지한다.
- 조회 실패 대체 문구에 예측시장 수치를 작성하거나 추정하지 말고 자료가 없다고 명시하도록 지시한다.
- 실패 기록을 drain할 때 실행 단위 차단 상태도 초기화한다.

## Out of Scope

- Polymarket API의 대체 공급자 도입 또는 연결 설정 변경
- HTTP 상태 오류와 데이터 파싱 오류의 재시도 정책 변경
- 기존 보고서에서 과거에 생성된 확률의 출처를 소급 판정
