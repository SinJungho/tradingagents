## MODIFIED Requirements

### Requirement: 공시 대상 선택 목록

스크립트는 `--list`로 사용자가 고를 수 있는 대상 목록을 80칸 터미널에 맞는 ASCII 표로 출력해야 한다 (MUST). 13F 목록은 투자자 표(번호·인물·운용사·CIK)와 기관 표(번호·기관·CIK)로 나눈 고정 목록이며, 번호는 두 표에 걸쳐 이어진다. 하원 목록은 최근 3년 하원 색인의 PTR 신고 건수 상위 의원을 번호·이름·지역구·건수로 보인다. 하원 목록은 유명도가 아니라 신고 건수 기준임을 밝혀야 한다 (MUST). 하원 색인 조회에 실패하면 13F 목록은 그대로 출력하고 하원 목록 자리에 실패를 알린다.

#### Scenario: 목록 출력

- **WHEN** 사용자가 `--list`로 실행할 때
- **THEN** 13F 투자자 표, 13F 기관 표, 하원 PTR 상위 표를 번호와 함께 출력하고 조회를 실행하지 않는다

#### Scenario: 하원 색인 실패

- **WHEN** `--list` 실행 중 하원 색인을 읽지 못할 때
- **THEN** 13F 표는 출력하고 하원 목록 자리에 조회 실패를 표시한다
