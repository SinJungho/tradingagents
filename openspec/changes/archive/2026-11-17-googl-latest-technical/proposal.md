# GOOGL 최신 기술 분석

## Why
기존 고정 종목 사건 평가와 분리하여 GOOGL/SPY의 최신 완료 정규 세션을 실데이터로 분석하고 실제 차트를 제공한다. 사용자 실행 계획을 승인된 범위로 삼는다.

## What Changes
명시적 종목·벤치마크 입력, 재개 가능한 최대 5년 수집, 지표·구조선·민감도 및 3개 차트와 한국어 보고서를 추가한다. 기존 실험 해시를 보존하고 새 실행 ID와 가격 48회·추가 자료 40회 예산을 사용한다. 출처 미검증 SPO·가격별 거래량·심리는 평가 불가로 구분한다.

## Out of Scope
주문, WTS 연동, 유료 LLM 토론, 예측력 비교 백테스트, 기존 사건 성공률 재사용.
