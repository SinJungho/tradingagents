## ADDED Requirements

### Requirement: 명시적 최신 분석 입력과 자료 계약
시스템은 분석 종목과 벤치마크를 명시적으로 받아 마지막 완료 XNYS 세션의 동일 저장 OHLCV를 사용하고 MUST 보간하지 않는다. 기존 실험 설정·해시는 보존한다.

#### Scenario: GOOGL 최신 분석
- **WHEN** GOOGL과 SPY를 입력한다
- **THEN** 새 실행 ID에 기준 세션·출처·해시·누락·누적 호출량을 기록하고 기존 사건 성과를 재사용하지 않는다.

### Requirement: 인과적 지표와 실제 차트
시스템은 사용자 계획의 모든 지표 상태를 기록하고 SHALL 252세션 종합·126세션 구조·보조지표 차트와 한국어 Markdown 및 HTML을 생성한다. 피벗은 좌우 2봉 확정 이후 사용하고 구조선은 3접점·0.25ATR 및 0.1/0.5 민감도를 제공한다.

#### Scenario: 미확보 출처
- **WHEN** SPO 원본 또는 가격별 거래량 또는 공개 시각을 검증하지 못한다
- **THEN** 해당 항목을 평가 불가로 표시하고 사용 가능한 계산과 시각화를 계속한다.

### Requirement: 재개와 검증
시스템은 가격 48회·추가 자료 40회 예산을 재개에도 유지하고 MUST 오류·429를 이력 종료로 처리하지 않는다. 합성 테스트와 실제 렌더링 검증을 수행한다.

#### Scenario: 동일 실행 재개
- **WHEN** 동일 ID로 다시 실행한다
- **THEN** 정상 캐시를 재사용하며 기존 요청과 예산을 초기화하지 않는다.

#### Scenario: 최근 정상 캐시의 세션 확장
- **WHEN** 최신 XNYS 세션이 직전 정상 Toss 캐시보다 30일 이내 뒤로 이동한다
- **THEN** 기존 전체 구간을 다시 받지 않고 같은 USD·adjusted 기준의 겹치는 캔들을 일치 검증한 뒤 새 세션을 합치며, 연장 호출도 예산에 기록한다.
