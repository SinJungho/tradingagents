# 공시 스냅샷 표 테두리

## Why

요약·13F 보유·하원 거래가 공백 정렬만으로 나뉘어 있어, 행이 많으면 열 경계와 표의 시작·끝이 눈에 잘 들어오지 않는다(2026-11-19 사용자 요청). 열 구성은 그대로 두고 표로 구분한다.

## What Changes

- 대상 요약, 13F 상위 보유, 하원 거래 목록을 ASCII 테두리(`+`, `-`, `|`) 표로 그린다. 열과 순서는 바꾸지 않는다.
- 테두리 문자는 터미널마다 폭이 다를 수 있는 선 그리기 문자(─│┼) 대신 ASCII만 쓴다.
- 78칸 안에 들도록 13F 종목 칸을 26칸에서 24칸, 요약 대상 칸을 24칸에서 22칸으로 줄인다.

## Out of Scope

- 열 추가·삭제, 다른 출력 블록(원문 링크, 신규·미보고 목록, 해석 한계)의 형식
