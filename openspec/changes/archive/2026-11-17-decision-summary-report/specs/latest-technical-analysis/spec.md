## ADDED Requirements

### Requirement: 판단 요약 보고서
시스템은 최대 이력 실행에서 SHALL 판단 요약 HTML을 `report.html`로 생성한다. 요약은 결정론적 기술 판단, 기준 종가와 가장 가까운 지지·저항 후보 및 거리, ATR·RSI·SPY 대비 상대강도·최근 252세션 낙폭, 일봉·월봉·연봉 추세, 조건부 시나리오와 무효화 조건, 다음 월봉·연봉 확정 세션, 핵심 차트, 자료 한계를 포함한다. 값이 없으면 평가 불가로 표시하며 목표가·기대수익률을 표시하지 않는다. 기존 상세 내용은 `report.md`와 `report_detail.html`에 보존한다.

#### Scenario: 경계와 평균을 계산할 수 없음
- **WHEN** 지지·저항 후보나 월봉·연봉 평균이 없다
- **THEN** 해당 칸은 평가 불가로 표시되고 보고서 생성은 실패하지 않는다.

#### Scenario: 상세 분석 접근
- **WHEN** 사용자가 요약 페이지를 연다
- **THEN** 12개 순위 분석이 있는 상세 보고서 링크와 전체 지표 표를 접힘 영역에서 확인할 수 있다.

### Requirement: LLM 그래프 결정 분리 표시
시스템은 같은 종목·기준일의 LLM 그래프 최종 결정 파일이 있으면 SHALL 등급과 요약을 기술 판단과 별도 영역에 출처 경로와 함께 표시한다. 그래프의 가격 기준일이 다를 수 있음을 함께 표시하고, 파일이 없으면 미실행으로 표시한다.

#### Scenario: 그래프 미실행
- **WHEN** 최종 결정 파일이 없다
- **THEN** LLM 영역은 미실행과 실행 방법을 표시하고 기술 판단은 그대로 생성된다.
