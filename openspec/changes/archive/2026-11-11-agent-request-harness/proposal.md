# 반복 투자 리서치 요청 하네스

## Why

포트폴리오 점검, 종목 발굴, 종목 분석, 투자 시나리오 요청이 반복될 때 저장소 에이전트가 매번 다른 순서와 기본값으로 처리한다. 같은 유형의 요청에는 같은 절차가 적용되도록 에이전트 작업 규칙을 고정해야 한다.

## What Changes

- `AGENTS.md`에 요청 유형 4가지와 유형별 기본 처리 흐름을 추가한다.
- 저장소에서 확인 가능한 정보는 다시 묻지 않고, 결과에 필요한 사용자 입력이 없을 때만 질문하도록 규정한다.
- 미구현 기능은 실행된 것처럼 보고하지 않고 OpenSpec 변경 작업으로 안내하도록 규정한다.
- 실계좌 조회와 LLM 분석은 사용자의 명시적 요청이 있을 때만 실행하도록 규정한다.

## Out of Scope

- 앱 코드·CLI·LangGraph 변경. `AGENTS.md` 규칙만으로 런타임 앱이 자동 분석을 실행하지 않는다.
- 종목 발굴·비교 명령, 스크리너 공급자, 투자자 역할 체계, 역할별 백테스트, 관심 종목 추적 구현.
- 주문·정정·취소·조건주문 또는 자동매매 기능.
