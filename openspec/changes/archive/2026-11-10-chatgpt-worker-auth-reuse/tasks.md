## Verification

- 집중 테스트 89개 통과. 최초 샌드박스 실행의 콜백 바인딩 차단 7건은 로컬 포트 권한을 허용한 재실행에서 통과했다.
- 전체 pytest: 1,566개 통과, 1개 선택 의존성(langchain_aws) 미설치로 건너뜀, 하위 검사 103개 통과.
- Ruff, 설치된 CLI 도움말, diff 공백 검사 통과.
- 합성 홈의 4개 동시 프로세스가 갱신을 1회만 수행하고 새 프로세스 2회에서 재사용했다. 별도 홈에서는 로그인 명령을 안내했다.
- 실제 로컬 Orca 터미널 2개에서 사용자 홈 일치와 기존 자격 증명 반환을 확인했다. 새 로그인이나 홈 설정 변경은 필요 없었다. doctor는 두 chatgpt 계층의 인증 저장 상태와 API 도달 가능을 표시했다. ORCA_ENVIRONMENT 미노출은 안내로 유지했다.
- 실제 LLM 호출 및 브로커 계좌 조회는 수행하지 않았다. 인증 파일 내용과 토큰은 출력하거나 복사하지 않았다.

## Remaining User Action

브로커 읽기 전용 권한의 확인 근거가 없으므로 TOSS_BROKER_READ_ONLY_VERIFIED는 설정하지 않았다. 브로커 사용 전 별도 권한 확인이 필요하다. 인증 재사용 구현의 완료와는 별개다.
