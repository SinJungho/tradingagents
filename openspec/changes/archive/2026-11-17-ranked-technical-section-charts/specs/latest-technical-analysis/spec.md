## ADDED Requirements

### Requirement: 순위별 분석과 차트 연결
시스템은 12개 순위별 기술 분석의 각 설명과 대응하는 SVG 차트를 Markdown 및 HTML 보고서에 함께 표시하는 MUST 요구사항을 충족한다. 차트는 보고서와 같은 저장 OHLCV 및 지표 결과를 사용하며 기준일 이후 값을 포함하지 않는다. 원자료를 검증할 수 없는 항목은 실제 차트 대신 평가 불가 상태를 표시한다.

#### Scenario: 지표별 차트 표시
- **WHEN** 12개 지표별 기술 보고서를 생성한다
- **THEN** 각 순위 항목에 해당 지표를 읽을 수 있는 차트가 삽입된다.

#### Scenario: Volume Profile 자료 미확보
- **WHEN** 검증된 가격별 거래량 자료가 없다
- **THEN** Volume Profile 영역에는 평가 불가 안내가 표시되고 임의로 만든 분포도는 포함되지 않는다.
