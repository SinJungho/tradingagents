# 순위별 분석에 개별 차트 삽입

## Why
12개 지표별 관찰과 해석은 보고서에 있지만, 독자가 각 설명과 해당 가격·보조지표 흐름을 바로 대조하기 어렵다.

## What Changes
각 분석 항목 바로 아래에 동일 저장 OHLCV와 계산 지표로 만든 SVG 차트를 Markdown 및 HTML 보고서에 삽입한다. Volume Profile은 검증 자료가 없을 때 실제 프로파일 대신 평가 불가 안내 패널을 표시한다.

## Out of Scope
가격 자료·지표 설정·분석 시나리오를 변경하지 않는다. 자료가 없는 지표의 수치를 추정하거나 합성하지 않는다.
