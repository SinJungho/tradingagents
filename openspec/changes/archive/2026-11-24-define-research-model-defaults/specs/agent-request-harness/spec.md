## ADDED Requirements

### Requirement: 새 세션의 리서치 모델 설정

에이전트는 요청 유형에 맞는 스킬과 저장소 모델 표를 읽고, 사용자가 따로 지정한 값을 우선해 LLM 명령의 실행 환경에 해당 기본값을 적용해야 한다(MUST). 계산·조회 전용 경로는 앱 LLM을 호출하지 않아야 한다(MUST).

#### Scenario: 일반 종목 분석과 심층 포트폴리오
- **WHEN** 사용자가 모델을 지정하지 않고 종목 분석 또는 심층 포트폴리오 점검을 요청한다.
- **THEN** 일반 종목 분석은 Luna 6·Sol 6.1과 공통 medium을, 심층 포트폴리오는 Sol 6.2·Sol 6.1과 공통 high를 적용한다.

#### Scenario: 차트 스킬로 작업
- **WHEN** 새 세션에서 차트 분석 또는 드로잉을 요청한다.
- **THEN** 계산은 기존 CLI에 맡기며, Codex 실행을 시작할 때 모델 설정이 가능하면 Sol 6.2 medium을 기본으로 사용한다. 이미 열린 세션에서 스킬 호출로 모델이 바뀐 것으로 보고하지 않는다.
