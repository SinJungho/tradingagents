- 첫 화면은 근거 상태별 개수와 부분·미확인 사유를 섹션별로 요약한다. 반복적인 빈 제한·비고 필드는 생략한다.

## 남은 제한

- S&P 구성 자료는 2차 출처이며 구성 기준일을 확인할 수 없었다. 이 표본은 과거 구성 기준 시장 폭을 복원하지 않는다.
- 달러 지수 값은 Yahoo 요청의 HTTPError로 unavailable이다.
- 실적 발표값·가이던스는 검증된 발표 시각·실제값·예상값을 확보하지 못해 계산하지 않았다. 실적 일정은 AAPL·MSFT·NVDA·AMZN·GOOGL·META·TSLA 표본뿐이며 전체 기업 일정을 보장하지 않는다.
- FRED 일정은 날짜만 제공할 수 있으며, BEA/Fed가 확인되지 않은 일정 전체까지 망라하지 않는다. 보고서는 일정이 없다고 단정하지 않는다.
- 새 보고서는 실용적인 시장 요약이지만 `불완전 보고서` 상태를 유지한다. 100점 점수와 자동 계산은 사실성 보증이 아니다.
- 사용자가 집 네트워크에서 Polymarket 공개 연결을 확인할 수 없다고 지정한 항목은 이 보고서 평가 범위가 아니며 열린 상태다.
