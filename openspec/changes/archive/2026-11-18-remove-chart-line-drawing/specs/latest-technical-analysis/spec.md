## MODIFIED Requirements

### Requirement: 우선순위별 기술 분석 포함
시스템은 보고서에 사용자가 제시한 9개 지표를 순위대로 싣고 각 항목의 목적·추천도·최신 차트 관찰값·조건부 해석을 포함하는 MUST 요구사항을 충족한다. 값을 검증할 수 없는 항목은 사유와 함께 평가 불가로 표시하며, 지표 계산 성공만으로 예측력을 주장하지 않는다.

#### Scenario: 실제 지표 해석 포함
- **WHEN** 최신 기술 보고서를 생성한다
- **THEN** 9개 지표가 사용자 순위대로 실제 계산 결과에 근거해 해석된다.

#### Scenario: 가격별 거래량 자료 미확보
- **WHEN** 검증된 Volume Profile 가격별 거래량 자료가 없다
- **THEN** 9위 항목을 평가 불가로 표시하고 일봉 거래량으로 POC·VAH·VAL을 만들어 내지 않는다.

### Requirement: 순위별 분석과 차트 연결
시스템은 9개 순위별 기술 분석의 각 설명과 대응하는 SVG 차트를 Markdown 및 HTML 보고서에 함께 표시하는 MUST 요구사항을 충족한다. 차트는 보고서와 같은 저장 OHLCV 및 지표 결과를 사용하며 기준일 이후 값을 포함하지 않는다. 원자료를 검증할 수 없는 항목은 실제 차트 대신 평가 불가 상태를 표시한다.

#### Scenario: 지표별 차트 표시
- **WHEN** 9개 지표별 기술 보고서를 생성한다
- **THEN** 각 순위 항목에 해당 지표를 읽을 수 있는 차트가 삽입된다.

#### Scenario: Volume Profile 자료 미확보
- **WHEN** 검증된 가격별 거래량 자료가 없다
- **THEN** Volume Profile 영역에는 평가 불가 안내가 표시되고 임의로 만든 분포도는 포함되지 않는다.

### Requirement: 인과적 지표와 실제 차트
시스템은 사용자 계획의 모든 지표 상태를 기록하고 SHALL 252세션 종합·보조지표 차트와 한국어 Markdown 및 HTML을 생성한다. 선 후보는 만들지 않는다.

#### Scenario: 미확보 출처
- **WHEN** SPO 원본 또는 가격별 거래량 또는 공개 시각을 검증하지 못한다
- **THEN** 해당 항목을 평가 불가로 표시하고 사용 가능한 계산과 시각화를 계속한다.

### Requirement: 최신 기술 차트 가독성
시스템은 최신 기술 분석 차트에서 축 값, 기간 눈금, 범례와 최신 지표 값을 읽을 수 있는 크기로 표시해야 한다. 평가할 수 없는 지표는 큰 빈 그래프 대신 간결한 상태로 표시해야 한다. HTML은 작은 화면에서도 차트의 가로세로 비율과 글자 크기를 보존해야 한다. 이 요구사항은 MUST 충족해야 한다.

#### Scenario: 최신 분석 차트 생성
- **WHEN** 최신 기술 분석의 Markdown과 HTML 산출물을 생성한다
- **THEN** 가격·보조지표 차트에서 눈금과 핵심 값이 읽히고 평가 불가 상태가 함께 확인된다.

#### Scenario: 좁은 화면에서 HTML 열기
- **WHEN** 보고서를 좁은 화면에서 연다
- **THEN** 차트의 글자와 비율을 유지하고 가로 스크롤로 전체 차트를 확인할 수 있다.

### Requirement: 기술 보고서 해석과 차트 정확성
시스템은 지표 관찰값에 근거한 해석만 출력하고 SHALL 동일 날짜의 막대와 선을 같은 x좌표에 표시한다.

#### Scenario: 가까운 피벗과 먼 선정 선
- **WHEN** 지표 차트를 생성한다
- **THEN** 선 후보나 피벗 기반 경계는 만들거나 표시하지 않는다.

#### Scenario: 조건에 따른 해석
- **WHEN** 지표 값이 해석 구간에 있다
- **THEN** 관찰값에 근거한 해석만 쓰고 단정하지 않는다.

#### Scenario: 복합 패널 렌더링
- **WHEN** MACD 선과 히스토그램을 함께 표시한다
- **THEN** 동일 날짜의 중심 좌표가 일치하며 모든 범례가 SVG 안에 표시된다.

### Requirement: 가격 패널 캔들 표시
시스템은 가격 축 섹션 차트에서 SHALL 종가 선 대신 저장 OHLC 캔들을 그린다. 상승 봉은 빨강, 하락 봉은 파랑이며 OHLC 중 하나라도 없으면 해당 봉을 그리지 않는다.

#### Scenario: 볼린저 섹션 차트
- **WHEN** 볼린저 밴드 섹션 차트를 생성한다
- **THEN** 각 세션은 심지와 몸통의 캔들로 표시되고 밴드 선은 그 위에 함께 표시된다.

### Requirement: 판단 요약 보고서
시스템은 최대 이력 실행에서 SHALL 판단 요약 HTML을 `report.html`로 생성한다. 요약은 결정론적 기술 판단, ATR·RSI·SPY 대비 상대강도·최근 252세션 낙폭, 일봉·월봉·연봉 추세, 다음 월봉·연봉 확정 세션, 핵심 차트, 자료 한계를 포함한다. 값이 없으면 평가 불가로 표시하며 목표가·기대수익률을 표시하지 않는다. 기존 상세 내용은 `report.md`와 `report_detail.html`에 보존한다.

#### Scenario: 경계와 평균을 계산할 수 없음
- **WHEN** 월봉·연봉 평균이 없다
- **THEN** 해당 칸은 평가 불가로 표시되고 보고서 생성은 실패하지 않는다.

#### Scenario: 상세 분석 접근
- **WHEN** 사용자가 요약 페이지를 연다
- **THEN** 9개 순위 분석이 있는 상세 보고서 링크와 전체 지표 표를 접힘 영역에서 확인할 수 있다.

### Requirement: 문장형 보고서 문구
시스템은 판단 요약 페이지의 판정 근거, 주의 문구와 차트 캡션을 SHALL 조사와 서술어가 있는 문장으로 생성하고, 가운뎃점·세미콜론·화살표로 값을 나열하지 않는다. 숫자, 조건, 목표가·실행 신호·예측력에 대한 고지는 바꾸지 않는다.

#### Scenario: 이동평균 위치가 섞임
- **WHEN** 종가가 SMA20 위, SMA50 아래이고 SMA200 값이 없다
- **THEN** 판정 근거는 문장으로 표시된다.
