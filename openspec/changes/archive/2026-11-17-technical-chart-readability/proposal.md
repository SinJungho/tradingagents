# 최신 기술 차트 가독성 개선

## Why

현재 최신 기술 분석의 구조 차트는 여러 후보 ID가 작은 글자로 한쪽에 몰리고, 보조지표 차트는 축 값 없이 넓고 얇게 그려져 실제 보고서 검토와 공유에 불편하다.

## What Changes

- 차트의 글자, 날짜 눈금, 값 축과 최신 지표 값을 읽기 쉽게 조정한다.
- 구조 차트에는 조건부 시나리오에 쓰이는 가까운 지지·저항 후보를 중심으로 표시하고, 전체 후보와 ID는 보고서 표 및 JSON/CSV에서 확인하게 한다.
- 자료 미확보 지표는 큰 빈 패널 대신 간결한 상태로 표시한다.
- HTML과 Markdown 보고서에서 차트를 바로 열고 작은 화면에서도 가로로 확인할 수 있게 한다.

## Out of Scope

- 가격 자료, 지표 계산, 후보 순위, 시나리오 경계 계산은 바꾸지 않는다.
- 새 이미지 라이브러리, LLM 호출, 브로커 호출은 추가하지 않는다.
