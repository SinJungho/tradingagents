## ADDED Requirements

### Requirement: 최신 기술 차트 가독성
시스템은 최신 기술 분석 차트에서 축 값, 기간 눈금, 범례와 최신 지표 값을 읽을 수 있는 크기로 표시해야 한다. 구조 차트는 조건부 시나리오에 사용되는 가까운 지지·저항 후보를 중심으로 표시하고 MUST 전체 후보 세부 정보를 보고서 표 또는 JSON/CSV에 보존해야 한다. 평가할 수 없는 지표는 큰 빈 그래프 대신 간결한 상태로 표시해야 한다. HTML은 작은 화면에서도 차트의 가로세로 비율과 글자 크기를 보존해야 한다.

#### Scenario: 최신 분석 차트 생성
- **WHEN** 최신 기술 분석의 Markdown과 HTML 산출물을 생성한다
- **THEN** 가격·보조지표 차트에서 눈금과 핵심 값이 읽히고, 구조 차트의 주요 경계가 명확하며, 전체 후보 데이터와 평가 불가 상태가 함께 확인된다.

#### Scenario: 좁은 화면에서 HTML 열기
- **WHEN** 보고서를 좁은 화면에서 연다
- **THEN** 차트의 글자와 비율을 유지하고 가로 스크롤로 전체 차트를 확인할 수 있다.
