# 차트 드로잉 완료 증거 검증

## Why

차트 가격 자료 대조를 마쳐도 표시가 실제 사용자 탭에서 유지되는지는 다시 열어 확인해야 한다. 저장된 작업 증거로 추가·재사용 완료 여부를 재현할 수 있어야 한다.

## What Changes

- 읽기 전용 `chart-drawings-check`에서 버전이 있는 요청, 차트 데이터 검증, 변경 전·직후·재열기 후 조회 원문, 화면 확인 기록과 캡처를 검사한다.
- 추가·재사용한 구간과 추세선별 판정 및 미완료 사유를 출력한다. Tratto 스킬에 기록 형식과 실행 방법을 추가한다.

## Out of Scope

- 교체·삭제의 CLI 검증, UI 조작, 백테스트 예측력 검정
