## ADDED Requirements

### Requirement: 추가·재사용 드로잉 증거 검사

저장소 에이전트 MUST Tratto에서 구간이나 추세선을 추가·재사용할 때 버전이 있는 `drawings.json`에 대상 탭·종목·일봉·기준일과 사전 좌표를 남기고 `chart-drawings-check --drawings <drawings.json> [--json]`으로 결과를 확인해야 한다. CLI MUST 증거를 읽기 전용으로 검사하고 항목별 사유와 종료 코드 0(완료), 1(증거 부족·불일치), 2(입력 읽기·해석 실패)를 반환해야 한다.

#### Scenario: 검증한 차트에서 추가 또는 재사용

- **WHEN** 해당 종목·기준일의 `chart-check`가 `ok`이거나 5년 일봉 경로에서 거래일·OHLCV 검증을 통과하고, 같은 탭의 변경 전·직후·재열기 후 조회 원문과 재열기 화면 확인·캡처가 있을 때
- **THEN** 추가는 일치 객체 수 0→1→1, 재사용은 1→1→1인 항목에 한해 완료로 표시한다
- **AND** 종류와 거래일·십진수 가격 좌표로 일치 여부를 판단한다

#### Scenario: 필수 증거 누락 또는 불일치

- **WHEN** 이전 형식이거나 데이터 검증, 대상 탭, 좌표, 객체 수, 재열기 화면 확인 또는 캡처가 부족하거나 불일치할 때
- **THEN** 기록을 보존하고 누락이나 불일치 사유를 표시하며 종료 코드 1을 반환한다

#### Scenario: 백테스트 미결

- **WHEN** 드로잉에 필요한 증거가 모두 맞고 백테스트만 미결일 때
- **THEN** CLI는 드로잉 완료를 반환하고 예측력은 별도로 보고한다
