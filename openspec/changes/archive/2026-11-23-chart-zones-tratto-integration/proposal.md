# Yahoo 일봉 차트 구간 및 Tratto 연동

## Why

2026-11-18 변경은 저장소 안의 차트 선 후보·기술 분석·`technical-backtest`·`chart-eval`을 제거했다. 이 변경은 그 삭제를 되돌리지 않고, Yahoo 일봉으로 결정론적 가격 구간만 계산해 기존 분석 도구와 CLI에 제공하고 Tratto는 표시·앵커 확인에만 쓰는 별도 기능을 제안한다. LLM은 계산·구간 선택·가격 수정에 관여하지 않는다.

현재 `route_to_vendor`는 등록된 도구 메서드만 라우팅하며 일반 Yahoo OHLCV 경로는 `auto_adjust=True`와 결측 채움을 사용한다. 따라서 차트 구간용 미조정 종가 기준의 보존 데이터는 기존 도구에 억지로 끼우지 않고 별도 Yahoo 어댑터와 오류 기록 경로를 설계한다. 그래프 분석 도구는 `market_analyst.TOOLS`와 `build_analyst_execution_plan`을 통해 등록되며, `InjectedState` 기반 날짜 경계 및 `collect_tool_evidence` 근거 수집을 따른다.

## What Changes

- 기본 48종목에 토스 계좌에서 읽기 전용으로 확인한 **미국 상장** 보유 ticker를 중복 없이 추가한다. 현재 보유 종목을 구간 비교·표시·평가 처리 순서에서 우선하며, 보유 추가분은 별도 평가 코호트로 보고한다. 한국 상장 보유 종목은 XNYS 기준 v1 표본에서 제외한다. 이는 표본 선택용 조회이며 제거한 Toss 일봉 분석을 복구하지 않는다.
- 단계 1: Yahoo 일봉 스냅샷으로만 동작하는 v1 구간 계산기, 단일 종목 분석용 Market Analyst 도구, 결정론적 다종목 `chart-zones` CLI와 합성 테스트를 추가한다.
- 단계 2: Tratto 입력 CSV를 비교하고 내보내기 시간대를 지정할 수 있는 `chart-check`와 브라우저에서 표시·앵커를 검증하는 저장소 밖 skill을 추가한다. 차트 일치 상태와 통계 검증 상태를 서로 독립적으로 표시한다.
- Tratto Skill에 5년 OHLCV 전후 5봉 분석 절차와 목적별 보조 도구 선택을 추가한다. 이 작업은 v1 계산기와 별도로 수행한다.
- 단계 3: 고정 표본만 사용하는 `zone-backtest`와 append-only 평가 기록을 추가한다. 미래 데이터 누출, 일봉 내 순서 불명, 의존 표본, baseline 공정성을 고려한 판정 설계를 사전 고정한다.
- 단계 4: 별도 사전 출처 점검을 통과한 뒤 13F 동적 표본을 point-in-time 방식으로 추가한다. 고정 48종목과 13F 추가분은 항상 별도 코호트로 관리한다.
- 파라미터는 `chart_zone_params=v1`로 고정하고 코드 상수와 references 문서에 동일하게 명시한다. 튜닝 결과로 검증 기간 파라미터를 바꾸지 않는다.
- 이전 `remove-chart-line-drawing` 및 `remove-technical-latest` 아카이브는 변경하지 않는다. 신규 기능은 Yahoo 기반 일봉 구간 계산만 포함하며 기존 선 후보, 피보나치, AVWAP, Toss 분석, 저장소 차트, 시장 전체 구간 검색, 수동 드로잉의 분석 반영, 주문·거래 호출을 포함하지 않는다.

## Out of Scope

- 주봉, 시장 전체 구간 계산, 목표가·수익률 산출, 매매 자동화.
- Tratto MCP 설정 변경, Tratto 자체 코드 포크, 런타임 MCP 없이 성공했다고 주장하는 브라우저 검증.
- 한국 상장 Toss 보유 종목을 XNYS 일봉 평가에 섞거나 13F 자료를 실제 공개되기 전 기준일 표본에 소급 편입.
- 13F 코호트를 고정 표본의 통계적 통과 기준에 합산.
- 실패 또는 판정 불가인 최신 평가가 과거 통과 기록을 유효한 통과로 보이게 하는 상태 표시.
