## ADDED Requirements

### Requirement: 시나리오 종합 형식 검증 실패 재요청

시스템 MUST 종목별 조사 결과를 만든 뒤 시나리오 종합 응답 추출 또는 형식 검증에서 `ValueError`가 발생하면, 기존 종합 입력에 고정된 형식 수정 지시를 추가해 종합 모델을 정확히 한 번 더 호출해야 한다. 재요청 메시지 MUST 이전 응답의 원문을 포함하지 않아야 한다. 시스템 MUST 이미 완료한 종목별 조사를 반복하지 않아야 한다. 두 번째 응답도 추출 또는 검증에 실패하면 해당 오류를 전파해야 한다.

#### Scenario: 첫 응답 형식 오류 후 재요청 성공

- **WHEN** 종합 모델의 첫 응답이 JSON 파싱 또는 형식 검증에 실패하고 두 번째 응답은 유효할 때
- **THEN** 시스템은 종목 조사를 다시 실행하지 않고 시나리오 보고서를 생성한다
- **AND** 종합 모델은 총 두 번 호출된다
- **AND** 두 번째 호출 메시지에는 첫 응답 원문이 없다

#### Scenario: 재요청 응답도 형식 오류

- **WHEN** 첫 응답과 단 한 번의 재요청 응답이 모두 형식 검증에 실패할 때
- **THEN** 시스템은 두 번째 검증 오류를 전파하고 종합 모델은 총 두 번 호출된다

#### Scenario: 첫 응답 형식 검증 통과

- **WHEN** 첫 종합 응답이 유효할 때
- **THEN** 시스템은 재요청 없이 보고서를 생성하고 종합 모델은 한 번 호출된다
