# 포트폴리오 시나리오 종합 형식 오류 재요청

## Why

종목별 시장 조사를 모두 마친 뒤 시나리오 종합 응답의 JSON 파싱이나 필드 검증이 실패하면 전체 실행 결과가 버려진다. 이미 완료한 종목 조사를 반복하지 않고, 형식 검증 실패에 한해 종합 모델에 한 번 더 형식을 요청해 조사 결과를 보존한다.

## What Changes

- 종합 응답 추출 또는 파싱에서 `ValueError`가 발생하면 원래 입력 메시지에 고정된 형식 수정 지시를 더해 종합 모델을 정확히 한 번 재호출한다.
- 재요청에 이전 응답 원문을 포함하지 않는다. 두 번째 응답도 검증에 실패하면 기존처럼 오류를 전파한다.
- 재요청 동작과 호출 횟수를 합성 응답으로 검증한다.

## Out of Scope

- 모델 호출 자체의 API 오류 재시도
- 종목별 조사 재실행, 구조화 출력 전환, 재시도 횟수 설정
