## ADDED Requirements

### Requirement: 분류된 API 실패와 제한된 재시도

시스템 MUST Toss API 실패를 연결·타임아웃·인증·권한·호출 한도·서버·응답 오류로 구분하고, 응답 본문과 자격 증명 및 계좌 식별자를 오류에 포함하지 않아야 한다. 연결·타임아웃·서버 오류는 유한 횟수만 재시도하고 인증·권한·할당량 초과는 반복하지 않아야 한다.

#### Scenario: 네트워크 오류

- **WHEN** Toss API DNS, 연결 또는 timeout 실패가 재시도 한도까지 반복될 때
- **THEN** 어댑터는 오류 분류와 retryable 상태를 제공하고 요청 횟수는 설정된 유한 상한을 넘지 않는다

#### Scenario: 인증·권한·호출 제한

- **WHEN** Toss API가 인증, 권한 또는 할당량 오류를 반환할 때
- **THEN** 오류에는 상태 분류만 남기고 응답 본문이나 계좌 정보를 출력하지 않으며, 인증·권한·할당량 초과를 재시도하지 않는다
