# 검증 기록

## 시작 상태와 병목

기존 구현은 섹션 간 동일 문자열 티커를 이미 중복 제거했다. 가격은 기존 Yahoo OHLCV 디스크 캐시를 사용하지만 `_closes`의 캐시 읽기와 별도 분할 조회는 심볼별 순차 실행이다. SEC는 기존 TTL 디스크 캐시가 있어도 티커마다 공통 company_tickers JSON을 다시 읽고 선형 탐색했다. 유니버스 조회와 Yahoo·SEC 호출이 실행 단계이며 새 출력에서 각 단계 소요 시간과 호출 수를 계측한다.

## 합성 비교

동일 합성 가격·빈 SEC·빈 분할 자료에 `AAA.A, AAA-A, BBB`를 입력했다. 변경 전 가격/SEC/분할 각 3회, 변경 후 각 2회 호출했다. 세 결과의 value/growth/quality=Abstain, momentum=Bullish는 동일했다. 각 티커의 구간 정보와 실패 정보도 유지한다. 공급자 별칭이 없는 기존 입력은 같은 횟수다.

단일 합성 실행 전체 시간은 전 0.00615초, 후 0.00411초였다. 네트워크가 없고 반복 통계가 없는 측정이므로 실제 시장 발굴의 속도 향상 수치로 사용하지 않는다. 공통 SEC 표의 실행 내 재사용은 별도 테스트로 두 종목·미등록 종목 조회에서 1회만 읽는 것을 확인했다. 실행이 끝나면 메모리를 해제하고 다음 실행은 새로 읽는다.

출처는 공식 Nasdaq Trader, Wikipedia 2차 목록, iShares ETF 대용치, Yahoo 시총 스크리너를 구분한다. 구성 기준일이 없으면 null/unknown으로 표시하고 조회 시각과 혼동하지 않는다. 기존 사용자 변경과 디스크 캐시 TTL은 보존했다.

## 최종 자동 검증

집중 테스트 147 passed. 전체 pytest 1784 passed, 1 skipped, 24 warnings, 103 subtests passed (24.39초). skip은 선택 의존성 langchain_aws 미설치. Ruff 전체 통과, 설치된 CLI 도움말 확인, OpenSpec strict 변경안 검증 통과.

최초 전체 실행의 7개 인증 테스트 실패는 샌드박스 loopback 바인딩 제한이었으며 가짜 서버만 허용한 재실행으로 통과했다. 신규 공급자 모듈의 계층 검사 실패는 dataflows로 이동해 해결했다. 실브로커·실LLM 호출 및 커밋은 하지 않았다.
