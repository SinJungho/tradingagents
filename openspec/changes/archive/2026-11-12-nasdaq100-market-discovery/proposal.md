# Nasdaq-100 종목 탐색

## Why

현재 `tradingagents discover --tickers`는 사용자가 직접 준 최대 10개 티커만 평가한다. 현재 Nasdaq-100 구성 종목 목록에 기존 결정론적 팩터 신호를 적용하고, 지수 구성 목록의 출처와 기준일을 결과에 남기는 경로가 필요하다.

## What Changes

- `tradingagents discover --universe nasdaq100` 경로를 추가하고 기존 `--tickers` 입력과 상호 배타적으로 유지한다.
- 공개적으로 읽을 수 있는 Nasdaq-100 종목 목록에서 티커와 명시된 기준일을 가져온다. 현재 자동 갱신 가능한 공개 목록의 출처와 기준일을 출력하며, 이 목록이 Nasdaq의 유료/로그인 GIW 데이터와 동일한 공식 피드가 아님을 밝힌다.
- 기존 `value`, `growth`, `quality`, `momentum` 점수만 각 구성 종목에 적용한다. 데이터 실패는 종목별로 격리하고 부분 결과를 표시하며, 합성 점수·순위·투자 추천·LLM 호출은 만들지 않는다.
- 점수 데이터 기준일과 유니버스 구성 기준일을 별도로 표시하고 결과 범위를 해당 Nasdaq-100 목록으로 한정한다.

## Out of Scope

- Nasdaq-100 과거 구성 목록의 시점별 재구성
- 다른 지수, 모든 미국 상장 종목 또는 사용자가 고른 임의의 시장 범위
- 새 팩터, 점수 기준 변경, 종목 간 순위, 매매 추천, 브로커 호출 또는 LLM 분석
