# QQQ 차트 가독성 피드백 반영

## 목적

반복된 QQQ·TQQQ 차트 피드백을 차트 skill과 하네스 요구사항에 반영한다. 역할별 색상, 가격과 가까운 라벨, 불필요한 객체 정리, 장기 추세선 후보 비교를 일관되게 검증한다.

## 변경 범위

- Tratto 차트 skill에 객체 정리 기준, 라벨 배치, 후보 비교 보고 방식을 추가한다.
- chart-zone-analysis와 agent-request-harness 요구사항 및 시나리오를 보강한다.

## 범위 제외

- 차트 도구 동작이나 투자 분석 코드를 변경하지 않는다.
