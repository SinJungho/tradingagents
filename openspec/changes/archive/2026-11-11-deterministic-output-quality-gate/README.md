# 결정론적 출력 품질 게이트 구현 메모

검토기는 보고서의 가격·목표가·확률·수익률·비율·변화 후보를 소수의 한국어·영어 표현 규칙으로 찾는다. 같은 실행에서 분석가 도구가 반환한 숫자 토큰과 비교하며, `(110 - 100) / 100 = 10%` 형태의 산술식은 입력 숫자가 도구 자료에 있고 결과가 맞을 때만 지원한다. 보고서의 Trader와 Portfolio Manager 문장에서는 제공된 티커의 서명 수량으로 롱·플랫·숏 상태를 정하고, 알려진 상태와 직접 충돌하는 표현만 경고한다.

도구 자료의 원문은 보고서나 게이트 경고에 복사하지 않는다. 보고서 경고에는 위치와 이유를 표시하고, 원래 모델 문장은 수정하거나 삭제하지 않는다. 검토 결과는 결정론적 규칙을 적용한 참고 사항이며 의미적 정확성의 증명이 아니다.

## 한계와 오탐·미탐

- 숫자 근거는 도구 응답에서 추출한 값 토큰만 보관하므로, 토큰이 일치해도 같은 종목·기간·단위·출처를 뜻한다고 증명하지 않는다. 날짜나 식별자처럼 우연히 같은 숫자가 도구 응답에 있으면 미확인 주장을 놓칠 수 있다.
- 가격 단위 환산, 반올림, 집계, 비율 산출 등 지원하지 않는 계산은 경고할 수 있다. 수치 문맥 탐지는 가격·목표·확률·수익·비율·변화에 관한 한정된 한국어·영어 표현과 통화·퍼센트 표시에만 적용되므로 다른 표현은 놓칠 수 있다.
- 보유 상태 규칙은 Trader와 Portfolio Manager의 명시적인 한국어·영어 문구만 다룬다. 인용, 복잡한 부정, 문장 사이에 분산된 조건은 오탐이나 미탐을 만들 수 있다. 조건부 표현은 충돌로 경고하지 않으며, 추천 등급만으로 보유 상태를 추론하지 않는다.
- 포트폴리오가 제공되지 않으면 보유 단정은 확인 불가 경고가 되고, 상태를 플랫으로 추정하지 않는다. 패턴 범위에 없는 보유 표현은 확인되지 않을 수 있다.
