# 결정론적 출력 품질 경고 게이트

## Why

기존 프롬프트와 구조화 출력 스키마는 근거 있는 수치와 보유 상태에 맞는 거래 표현을 요구한다. 그래도 최종 보고서에는 출처를 확인하기 어려운 수치나 제공된 보유 상태와 맞지 않는 문장이 남을 수 있다. 보고서 흐름에 결정론적 검토 경고를 추가해 검토할 부분을 드러내되, 경고가 완전한 의미 검증이라고 오해되지 않도록 한다.

## What Changes

- 보고서에 포함되는 수치 주장 후보를 동일 실행의 제공 자료와 대조하고, 근거가 확인되지 않는 후보를 경고로 표시한다.
- 명시된 입력과 재현 가능한 단순 계산에서 나온 값은 출처값과 구분해 검토한다. 구현이 재현할 수 없는 계산은 검증된 것으로 간주하지 않는다.
- Trader와 Portfolio Manager의 명시적인 보유 관련 표현을 해당 티커의 제공된 롱·플랫·숏 상태와 대조하고, 직접적인 모순만 경고한다.
- 경고는 결정론적이고 비차단적이며 원문을 자동으로 고치거나 지우지 않는다. 경고가 없다는 사실을 의미적 정확성의 증명으로 취급하지 않는다.

## Out of Scope

- 프롬프트 지침이나 기존 구조화 스키마의 대체, 출력의 자동 재작성 또는 추천 결정 차단
- LLM 또는 브로커를 이용한 검증, 외부 출처의 추가 조회, 투자 판단의 타당성 평가
- 모든 자연어 표현, 계산식, 언어를 이해하거나 의미적 정확성을 보장하는 검증기
- 새 계산 모델, 목표가 산출 또는 매매 주문 기능
