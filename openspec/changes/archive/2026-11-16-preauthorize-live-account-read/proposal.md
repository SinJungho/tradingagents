# 토스 실계좌 읽기 전용 조회 사전 허용

## Why

매수·매도·비중 요청은 현재 보유를 알아야 의미가 있는데, 지금은 대화마다 실계좌 조회 허용을 받아야 해서 에이전트가 매번 한 번 안내하고 Claude Code 훅도 `portfolio live` 실행마다 확인 창을 띄운다. 2026-11-16 TSLA 매수 시나리오 통합 시험에서도 허용 안내 때문에 보유를 반영하지 못하는 순수 종목 분석 경로로 진행했다. 저장소 소유자가 토스 실계좌 읽기 전용 조회를 항상 허용하기로 정했다.

## What Changes

- 저장소 에이전트는 `tradingagents portfolio live` 명령(읽기 전용 실계좌 조회와 그 기본 LLM 분석)을 사전 허용된 것으로 보고 따로 허용을 묻지 않는다. 포트폴리오 점검과 종목 시나리오는 실계좌 경로를 기본으로 쓴다.
- Claude Code 훅(`guard.py live`)과 Codex prefix rule은 `portfolio live`에 확인을 요구하지 않는다.
- `--ticker` 분석, `backtest`, `market-report`의 실제 LLM 실행은 지금처럼 사용자 요청과 확인을 받는다.
- 주문 호출 금지, 자격 증명·계좌 식별자·원본 응답을 기록·보고서에 남기지 않는 규칙은 그대로다.

## Out of Scope

주문 기능, 다른 LLM 실행의 사전 허용, 앱 코드의 토스 조회 동작 변경.
