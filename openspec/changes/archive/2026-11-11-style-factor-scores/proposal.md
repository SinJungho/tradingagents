# 스타일 팩터 점수와 예측력 평가

## Why

종목별 다중 관점 분석의 역할 체계로 실존 인물 페르소나 대신 "코드가 계산하는 스타일 점수 + LLM 서술" 혼합형을 채택했다. LLM 서술을 붙이기 전에, 코드 점수만으로 예측력이 있는지 먼저 확인해야 한다. 점수에 예측력이 없으면 그 위에 얹는 LLM 서술의 가치도 주장할 수 없다. 기존 백테스트는 5거래일 보유 기준이라 수개월~1년 지평의 가치·품질 신호를 채점하기에 맞지 않는다.

## What Changes

- 가치·성장·품질·모멘텀 4개 스타일 점수를 LLM 없이 결정론적으로 계산하는 모듈을 추가한다. 재무 자료는 SEC EDGAR 공시일 기준, 가격은 Yahoo OHLCV를 분석일까지만 사용한다.
- 자료가 부족한 스타일은 0이나 중립으로 채우지 않고 `Abstain`과 누락 지표로 보고한다.
- 티커·날짜 격자에서 스타일 신호를 계산하고, 스타일별 보유기간의 벤치마크 대비 초과수익으로 신호별 적중률·평균 초과수익을 집계하는 평가 기능과 `tradingagents style-backtest` 명령을 추가한다.
- 평가 결과에는 사용자가 고른 종목군의 생존편향, 중첩 보유기간, 배당 조정 가격 사용 등 한계를 함께 표시한다.

## Out of Scope

- Style Analyst LLM 노드와 그래프 연결. 평가에서 예측력이 확인된 경우 별도 변경으로 진행한다.
- 실존 투자자 페르소나, 매크로 스타일 역할, FMP 공급자 연동, 과거 지수 구성종목 유니버스.
- 임계값·가중치 튜닝, 주문·자동매매 기능.
