# style-factor-scores

LLM 없이 계산하는 가치·성장·품질·모멘텀 스타일 점수와 `tradingagents style-backtest` 예측력 평가를 추가한다.

## 평가 결과 (2026-11-11 실행)

- 표본: 미국 대형주 40개(AAPL, MSFT, NVDA, AMZN, GOOGL, META, TSLA, JPM, BAC, WFC, JNJ, PFE, MRK, UNH, XOM, CVX, KO, PEP, PG, WMT, HD, NKE, DIS, INTC, CSCO, ORCL, IBM, T, VZ, BA, CAT, GE, MMM, CVS, WBA, PYPL, F, GM, SBUX, TGT). WBA는 가격 자료가 없어 실패.
- 격자: 2022-12-01~2026-08-01, 30일 간격. 벤치마크 SPY. 보유기간은 가치·성장·품질 252거래일, 모멘텀 63거래일.

## 판정

어느 스타일도 신호 방향대로 초과수익이 정렬되지 않았다. 평균은 일부 고수익 종목에 끌리고, 중앙값으로도 순서가 나타나지 않는다. 예측력이 확인되지 않았으므로 Style Analyst LLM 서술 계층은 추가하지 않는다.

## 한계

- 오늘 고른 종목이라 생존편향이 있다.
- 월별 칸의 1년 보유기간이 겹쳐 독립 관측치 수는 표본 수보다 훨씬 적다.
- 3년 남짓한 기간은 대형 성장주 주도 장세에 치우쳐 있다.
- 배당 조정 가격을 써서 이익수익률이 배당수익률만큼 어긋날 수 있다.
- 임계값은 튜닝하지 않은 고정값이며 업종 상대 비교를 하지 않는다.
