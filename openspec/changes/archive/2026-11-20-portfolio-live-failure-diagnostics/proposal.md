# 포트폴리오 실행 실패 진단 보강

## Why

2026-11-20 실행 보고서에는 시나리오 종합 `ValueError`와 현재가 HTTP 401만 분류되어 있다. 보고서만으로 시나리오 응답의 실제 검증 항목이나 토스 인증 거부 사유를 특정할 수 없다. 재현 가능한 형식 오류는 안전한 단계·검증 항목과 함께 기록하고, 토스 읽기 전용 GET은 만료·무효 토큰일 수 있는 401에서 새 토큰으로 한 번 회복을 시도할 필요가 있다.

## What Changes

- 시나리오 종합 응답의 추출·JSON·스키마 검증 실패를 안전한 진단 코드로 표현하고, 형식 보정 재요청도 실패하면 성공한 종목 조사를 보존해 보고한다.
- 토스 현재가 GET이 401을 받으면 토큰 캐시를 무효화하고 새 토큰으로 한 번 재시도한다. 재시도도 401이면 인증 오류를 반환하고 반복 호출하지 않는다.
- 합성 응답과 모의 HTTP 테스트로 두 경로를 검증한다.

## Out of Scope

- 저장된 실행의 인증 거부 원인이나 특정 모델 필드 오류를 추정하는 것
- 토스 주문·정정·취소 또는 자동 매매 기능
- 실제 브로커·LLM 호출
