# 포트폴리오 분석 CLI

## 설치와 실행

저장소 가상환경을 쓰는 경우 프로젝트 루트에서 실행합니다. 새 환경이라면 프로젝트 의존성 설치는 기존 설치 안내를 따릅니다.

```sh
pip install .
tradingagents portfolio demo
tradingagents portfolio live --help
```

포트폴리오 CLI는 기존 대화형 단일 종목 분석과 별도 명령입니다.

`demo`는 고정된 합성 보유·잔고·주문·시나리오를 사용합니다. 토스 인증정보를 읽거나 HTTP 요청, LLM 호출, 원격 tracing을 수행하지 않습니다. JSON과 한국어 Markdown의 형식을 확인할 수 있습니다.

## 워커 API 진단

실패한 Orca 워커나 하위 에이전트의 **실행 환경에서** 다음 명령을 실행하면 현재 프로세스의 작업 디렉터리, 노출된 Orca 실행 환경, quick/deep LLM 제공자와 인증 설정 여부, Yahoo·SEC·Toss 및 설정된 선택형 API 호스트의 도달성을 확인합니다.

```sh
tradingagents doctor
```

진단은 선택된 LLM 호스트와 Yahoo·SEC·Toss, 설정된 Alpha Vantage·FRED·TypeSafe 호스트에 인증정보 없는 HTTP `HEAD` 요청만 보냅니다. 모델 호출이나 계좌 조회를 수행하지 않고 API 키의 유효성도 검증하지 않습니다. 환경변수 값, ChatGPT 인증 파일 내용, endpoint 주소, 응답 본문은 출력하지 않습니다. Orca 실행 환경이 프로세스에 전달되지 않으면 미노출로 표시합니다. `provider=chatgpt` 워커는 해당 실행 호스트에서 `tradingagents login chatgpt`로 로그인하세요. `provider=openai`, `openai_auth=chatgpt_plan`인 기존 경로만 `tradingagents auth connect`와 `tradingagents auth status`를 사용합니다. 두 인증 저장소는 별개이며 doctor는 선택된 경로의 저장 여부만 확인합니다(유효성 검증이나 갱신 없음). 동일 호스트·사용자의 로컬 워커는 로그인한 사용자 홈을 그대로 사용하고 불필요한 홈 덮어쓰기를 제거하세요. 작업마다 로그인하지 않으며 worktree/작업 디렉터리는 유지합니다. 기존 프로세스 잠금과 자동 갱신이 적용됩니다. 별도 원격 호스트·컨테이너는 해당 환경에서 한 번 로그인하세요. 콜백 포트를 열 수 없으면 같은 사용자·호스트의 일반 터미널에서 로그인하세요. 다른 Orca 호스트의 인증 파일을 복사하지 말고, 각 실행 호스트의 승인된 인증 경로를 사용하세요. 자격 증명을 프롬프트나 워커 메시지로 복사하지 마세요.

## 토스 조회

로컬 `.env` 또는 프로세스 환경에 다음 변수 이름을 설정합니다. 비밀 값은 저장소에 커밋하지 마세요.

```text
TOSS_CLIENT_ID
TOSS_CLIENT_SECRET
TOSS_BROKER_READ_ONLY_VERIFIED=I_ACKNOWLEDGE_READ_ONLY
```

정확한 확인 문자열은 CLI가 브로커에 요청하기 전에 거치는 사용자 확인 절차입니다. 브로커 권한을 설정하거나 읽기 전용 키임을 증명하지 않습니다. 공식 API 문서에서 키 단위 읽기 전용 권한을 확인하지 못했으므로, 토스증권에서 해당 키의 권한과 허용 범위를 확인한 후에만 실계좌 조회를 활성화하세요. 어댑터는 계좌·보유·매수 가능 금액·주문 이력 조회만 제공하며 주문을 생성·정정·취소하지 않습니다.

계좌 요약과 시나리오 분석을 실행합니다.

```sh
tradingagents portfolio live --account-ordinal 1
```

명령은 계좌 유형과 순번을 표시하고 선택한 계좌만 조회합니다. 비대화형 실행에서는 `--account-ordinal`을 지정해야 합니다. 터미널에서는 옵션을 생략하고 번호를 입력할 수 있습니다. 계좌 식별자, 주문 ID, 원시 브로커 응답은 프롬프트와 보고서에 넣지 않습니다.

주문 이력의 기본 기간은 최근 30일입니다. 90일을 넘는 범위와 미래 종료일은 거부합니다. OPEN 주문은 최대 1페이지, CLOSED 주문은 상태별 최대 3페이지·페이지당 100건까지 조회합니다. 거래내역은 가능한 전체 이력을 미결제 기록과 함께 최대 10페이지·페이지당 100건까지 조회합니다. 다음 페이지가 남으면 이력 기반 실현손익은 산출하지 않습니다. 보유 현황은 선택한 계좌 전체를 조회합니다.

종목 조사는 최대 10개까지 수행합니다. `--max-symbols`로 상한을 낮추고, `--symbol`을 반복해 보유종목 또는 관심종목을 선택할 수 있습니다. 한국 관심종목은 `005930.KS` 또는 `035720.KQ`, 미국 관심종목은 `MSFT` 또는 `BRK.B` 같은 공급자 티커로 지정합니다. 보유 한국 종목은 계좌 종목코드나 매핑된 공급자 티커를 지정할 수 있습니다. 지원되지 않는 시장·티커는 다른 종목으로 대체하지 않고 생략 사유를 기록합니다. 종목을 지정하지 않으면 반환된 보유 순서대로 상한까지 조사합니다. `--no-scenarios`는 종목 조사와 시나리오 LLM 호출을 건너뛰고 결정론적 포트폴리오 요약만 남깁니다.

실시간 시나리오 조사는 기존 `TRADINGAGENTS_*` 공급자·모델 설정을 사용합니다. 기본 빠른 모델은 `gpt-6-luna`이며 OpenAI reasoning effort는 `xhigh`, 기본 심층 모델은 `gpt-6.1-sol`입니다. `TRADINGAGENTS_OPENAI_REASONING_EFFORT`를 지정하면 두 OpenAI tier 모두 그 값으로 재정의됩니다. 기본 경량 경로는 종목별로 기존 TradingAgents의 Market, News, Fundamentals Analyst와 해당 데이터 도구를 실행하고, 전체 종목 조사 뒤 별도의 포트폴리오 종합 LLM 호출을 1회 수행합니다. 이 경로는 Bull/Bear 토론, Trader, Risk, Portfolio Manager 최종 결정을 실행하지 않습니다. 종목별 그래프는 최대 24단계, 분석가당 도구 라운드 3회이므로 한 종목당 분석 LLM 호출은 최대 12회입니다. 종목 수는 기본 최대 10개여서 최악의 경우 분석 호출은 최대 120회이며 포트폴리오 종합 호출 1회가 추가됩니다.

Trader·Risk·Portfolio Manager의 종목별 결정을 포함하려면 다음처럼 전체 워크플로를 명시합니다.

```sh
tradingagents portfolio live --account-ordinal 1 --full-workflow --max-symbols 4
```

전체 그래프는 각 종목에 Market·Sentiment·News·Fundamentals 분석, Bull/Bear 조사 토론, Research Manager, Trader, Aggressive·Neutral·Conservative Risk 토론, Portfolio Manager 최종 결정을 실행합니다. 그래프의 분석가 결과를 기간별 시나리오 조사에도 재사용하므로 분석가를 중복 호출하지 않습니다. Trader 계획, Risk 토론, 최종 등급·결정을 JSON과 Markdown 보고서에 기록합니다. 기본 경량 경로보다 LLM 호출량이 커질 수 있으니 `--max-symbols`를 낮추거나 `--symbol`로 종목을 좁히세요. 전체 그래프는 포트폴리오 정보를 종목별 메모리나 체크포인트에 기록하지 않습니다.

전체 그래프에는 지원되는 보유 종목의 심볼, 수량, 평균 매입가와 통화만 전달합니다. 실제 현금 잔고를 확인할 수 없어 현금은 미확인으로 둡니다. Toss의 매수 가능 금액은 현금 잔고로 전달하지 않습니다. 계좌 식별자, 주문 이력, 원시 브로커 응답은 그래프 입력에서 제외합니다. 전체 워크플로 결과도 분석 제안이며 주문을 생성하거나 실행하지 않습니다. `--full-workflow`는 `--scenarios`와 함께 사용해야 합니다.

경량 경로의 누락된 도구 날짜는 실행 기준일로 보완하고, 종목 뉴스는 기본 7일, 가격 이력은 기본 1년을 조회합니다. 기술 분석은 추세·모멘텀·변동성 기본 지표를 사용하며 검증된 시장 스냅샷을 마지막에 확인합니다. ETF·뮤추얼펀드는 기업 재무제표 대신 Yahoo의 펀드 개요·운용·자산군·보유종목 자료를 조회합니다. 기존 SDK 재시도는 `TRADINGAGENTS_LLM_MAX_RETRIES` 설정에 따라 별도로 발생할 수 있습니다.

기본 분석 기간은 단기 1–20거래일, 중기 1–6개월, 장기 6–24개월입니다. 다음 환경 변수의 `최소-최대` 값을 바꿔 범위를 조정할 수 있습니다.

```text
TRADINGAGENTS_PORTFOLIO_SHORT_DAYS=1-20
TRADINGAGENTS_PORTFOLIO_MEDIUM_MONTHS=1-6
TRADINGAGENTS_PORTFOLIO_LONG_MONTHS=6-24
```

단기는 최대 250거래일, 월 단위 기간은 최대 120개월까지 허용합니다. 설정한 값과 각 기간의 상승·기본·하락 시나리오를 보고서에 기록합니다. 수치 계산은 코드에서 수행하며, 근거가 없는 확률·예상 수익률·목표 가격은 출력하지 않습니다.

계좌 분석에는 Toss 계좌 요약, 보유별 손익률·일간 손익·수수료·세금, 통화별 비중과 집중도, 매수 가능 금액, 주문 요약, 거래 유형·자산군·결제 상태별 건수가 포함됩니다. 거래 상세는 계산을 위해 메모리에서만 정규화하며, 완전한 매수·매도 이력이 있고 원가를 재구성할 수 있을 때에만 통화별 가중평균원가 실현손익 추정치를 보고합니다. 이 값은 세무·회계 원장이 아닙니다. 거래별 행이나 금액은 보고서에 기록하지 않습니다. Toss 현재가와 최대 200개 수정주가 일봉으로 최대 10개 분석 종목의 수익률·이동평균·RSI·MACD·ATR·거래량 지표를 계산하며, 지표마다 필요한 기간보다 캔들이 짧으면 미확인으로 둡니다. 가격·캔들 기준 시각과 HTTP 조회 시각을 분리합니다. Toss API는 기업 재무제표·밸류에이션·시장 뉴스 공급원이 아니며 해당 자료는 기존 외부 조사 경로에 남습니다.

라이브 실행은 정규화된 보유 수량·평가액·매수 가능 금액 스냅샷을 `~/.tradingagents/portfolio/history.jsonl`에 추가합니다. 파일 권한은 `0600`, 디렉터리는 `0700`이며 실제 계좌 식별자는 저장하지 않습니다. 비교는 화면에 표시된 계좌 순번을 기준으로 하므로 계좌 목록 순서가 바뀌면 같은 계좌인지 확인할 수 없습니다. 보고서의 통화별 변화는 평가액과 매수 가능 금액 차이로, 입출금 조정 총수익률이나 실현손익으로 해석하면 안 됩니다. 토큰, 계좌 식별자, 주문 ID, 원시 계좌 응답은 LLM 입력에서 제외합니다. 다만 보유 요약과 종목별 분석 결과는 선택한 외부 LLM 제공자에 전송됩니다. 민감한 금융정보 전송을 허용하는 모델과 계정만 사용하세요. 분석 중 LangSmith/LangChain 원격 tracing은 비활성화됩니다.

시나리오는 조건부 분석 문장으로만 제공되며 목표 가격, 수익률 예측, 주문 지시를 만들지 않습니다. 상승·기본·하락별 근거, 촉매, 주요 위험, 관찰·검토 조건, 논리 무효화 조건과 포트폴리오 영향을 JSON과 Markdown에 제공합니다. 진입·추가 매수·비중 변경은 사용자가 검토할 조건으로만 기술합니다. 가격·뉴스 데이터의 제공자와 자료 기준 시각이 기존 분석 본문에 명시된 경우만 그 본문에 남깁니다. 별도로 노출되는 `TradingAgents analyst research output` 시각은 분석 생성 시각이며, 개별 원자료의 기준 시각으로 간주하지 않습니다.

어댑터는 [토스증권 공식 API 문서](https://developers.tossinvest.com/docs)와 [공식 OpenAPI 명세](https://openapi.tossinvest.com/openapi-docs/latest/openapi.json)에 기재된 계좌·보유·매수 가능 금액·OPEN/CLOSED 주문·거래내역·현재가·일봉·USD/KRW 환율 조회를 사용합니다. HTTP timeout·재시도·페이지 수를 제한합니다. 연결·타임아웃·인증·권한·요청 제한·서버 오류는 구분해 표시하며, 인증·권한·요청 제한 오류는 자동 반복하지 않습니다. 공급자 실패 시 나머지 결과는 보존하고 오류 범주와 재시도 가능 여부만 보고서에 표시합니다. 매입원가·손익은 토스 제공 값 또는 수량과 단가 자료가 충분할 때만 계산합니다. Toss 환율 API의 매매기준율로 KRW/USD 통합 합계를 계산하되, 환율은 참고값이며 응답의 유효 종료 시각 이후에는 적용하지 않습니다. 토스 보유 API는 KR/미국 주식만 반환하므로 해외 옵션·채권 거래가 거래내역에 보이더라도 현재 수량·평가액은 조회되지 않은 상태로 둡니다. 토스 보유 응답에는 평가 자료의 기준 시각이 없으므로 HTTP `Date`를 조회 시각으로 기록하고 자료 기준 시각은 미확인으로 둡니다. 활성 계좌 및 주문 유형 등 공식 문서상의 제약도 보고서와 함께 확인해야 합니다.

## 보고서 저장과 삭제

JSON은 명시된 Pydantic 보고서 스키마로 검증한 뒤 저장합니다. Markdown 보고서는 한국어입니다. 조회 시각, 주문 기간, 단위, 커버리지, 누락, 출처, 시나리오 근거와 한계를 포함합니다. 파일 기본 경로는 다음과 같습니다.

```text
~/.tradingagents/portfolio/
```

파일 권한은 새 디렉터리 `0700`, 보고서 `0600`으로 설정합니다. `--output-dir`로 저장 위치를 변경할 수 있습니다. 기본 경로의 생성 보고서를 삭제하려면 다음 명령을 사용합니다.


CLI는 브로커 원시 응답, 계좌 식별자, 인증정보를 보고서나 로컬 스냅샷에 저장하지 않습니다. 잔고·보유·분석 본문은 개인 금융정보이므로 출력 디렉터리를 로컬에서 비공개로 유지하세요. `--output-dir`을 바꿨다면 해당 위치의 생성된 `portfolio_*.json`과 `portfolio_*.md`를 직접 삭제하세요.
